# terra-forge

A native Linux editor for **Terraria character files** (`.plr`) — written in Rust, drawn with
`egui`. Edit your character's stats, inventory, equipment, banks and Journey-mode research
without the game running.

![terra-forge editing a character](docs/screenshot.png)

Terraria's own character files are encrypted and versioned; most editors are web toys or
Windows-only. This one is a real desktop app, opens the modern format (1.4.4.9 and
1.4.5.x), and is built around a single rule: **it will not write a file it cannot prove it
can reproduce byte for byte.**

## Features

* **Inventory & equipment** — 10×5 backpack, coins and ammo, the five misc slots (pet,
  light pet, minecart, mount, hook) and their dyes, plus all four equipment loadouts.
* **Banks** — piggy bank, safe, Defender's forge and void vault, 40 slots each.
* **Drag and drop** — pick an item up in one slot and drop it in another to swap; drag an
  item out of the browser onto a slot to add it. Right-click gives a menu (max stack,
  favourite, duplicate, clear), the mouse wheel adjusts stacks, middle-click duplicates.
* **Slot inspector** — the selected slot gets a real editor: item name and id, a searchable
  prefix picker (all 84 modifiers), exact stack count, favourite and clear.
* **Stash mode** — open a second character alongside the first and drag items straight
  between the two saves; each side saves independently, with its own backup.
* **Real item artwork** — sprites are decoded from your own game files, so slots show the
  actual Terraria art. Animated art (souls, pets) is drawn from its first frame instead of
  being squeezed to a quarter size. Without an installed game (or with the toggle off) you
  get rarity-coloured tiles instead.
* **Item browser** — 6,196 items with names, ids, rarity, stack limits and tooltips.
  Grouped into sections (weapons, armor, accessories, blocks, …) and subdivided by damage
  class or slot; typing switches to fuzzy search.
* **Character sheet** — name, difficulty, life/mana, all permanent upgrades (including the
  six 1.4.4 boosters), hair and seven colours.
* **Journey mode** — research is editable: filter the catalogue, set any item's exact
  progress, complete one item at a time, or research everything with a known goal in one
  click. Buffs are editable slot by slot.
* **Adjustable UI** — zoom 0.8–2.0 and slot size, remembered between runs.
* **Backups** — every save first copies the old file to `<name>.plr.bak`.

## Safety model

A `.plr` is AES-128-CBC over a versioned binary stream. Terraria appends fields as it
patches, so a naive parser silently eats the wrong bytes on a new game version.

Three things keep that from happening here:

1. **Round-trip proof.** Because the cipher uses a fixed IV, `decrypt → parse → serialize →
   encrypt` must be byte-identical. `terra-core` checks this before every write and refuses
   to save otherwise.
2. **Unknown bytes are preserved.** Anything after the last field the parser understands is
   kept verbatim and written back, so a field added in a future patch survives untouched.
3. **Backups.** The original file is copied to `<name>.plr.bak` first, and the new file is
   written to a temporary path, decrypted and compared before it replaces anything.

Supported: 1.4.4.x (format 269–279) and 1.4.5.x (315–326). Pre-1.4 saves (format ≤ 194) are
rejected with a clear message rather than guessed at.

**Close Terraria (and Steam, if the character is a Steam Cloud save) before saving.** The
game and the editor both write the same file; whoever writes last wins.

## Build

Needs Rust 1.95+ (eframe 0.37's MSRV) and a normal Linux desktop with Vulkan or OpenGL drivers.

```sh
git clone https://github.com/mg4466/terra-forge
cd terra-forge
cargo build --release
./target/release/terra-forge
```

Or install it:

```sh
cargo install --path crates/terra-gui     # puts `terra-forge` in ~/.cargo/bin
```

Character files are found automatically in:

* `~/.local/share/Terraria/Players/`
* Steam Cloud: `~/.local/share/Steam/userdata/<account>/105600/remote/players/`
* tModLoader: `~/.local/share/Terraria/tModLoader/Players/`

## Try it without risking a save

```sh
cargo run --release --bin tforge -- demo /tmp/demo.plr
./target/release/terra-forge /tmp/demo.plr
```

`tforge demo` writes a synthetic character with a plausible loadout, so you can poke at the
editor before pointing it at anything real.

## Command line

The same binary ships a headless companion, `tforge`:

```sh
tforge info      <file.plr>     # decode and summarise
tforge verify    <file.plr>     # decrypt → parse → serialise → encrypt == original bytes
tforge inventory <file.plr>     # list non-empty slots with real item names
tforge copy      <file.plr>     # save through the editor's save path, compare to the source
tforge selftest  <file.plr>     # apply edits, save, reload, assert every edit stuck
tforge demo      <file.plr>     # write a demo character
```

`tforge verify` is the useful one: run it on your own save after an update to confirm this
build still understands that format.

| `Aa` in the top bar | zoom and slot size |

## How the item data is made

Items live in `crates/terra-assets/data/items.json`, generated — not hand-written — by the
two scripts in `tools/`:

* `extract_from_install.py` reads the `ItemID` constants and the localized item names out of
  the **installed game** (`Terraria.exe`), so ids always match the version you actually run.
* `gen_items.py` merges those with a small stats snapshot (max stack, rarity, tags,
  research goals) and writes the embedded JSON.

Max stack and rarity only exist inside the game's compiled code, so items newer than the
snapshot keep their real name and get "estimated" stats shown as such in the browser.

Item artwork comes from the same install: `Content/Images/Item_<id>.xnb` are XNA content
containers, LZX-compressed with a per-chunk length prefix on top. Decoding one costs about
0.05 ms, so the editor decodes a sprite the first time it is drawn and keeps the result in a
small GPU cache — no import step, no atlas file, and art that always matches your game
version. Large sprites are shrunk to fit a slot, tiny ones (coins, blocks, torches) get an
integer 2× so they stay recognisable, and animated sheets (a soul is 22×88, four frames tall)
contribute only their first frame so the icon keeps its proper size.

To refresh the database after a game update:

```sh
pip install dnfile
python3 tools/extract_from_install.py ~/.local/share/Steam/steamapps/common/Terraria/Terraria.exe /tmp/ex.json
python3 tools/gen_items.py /tmp/ex.json tools/snapshot_1.4.4.9.json
cargo build --release
```

## Limitations

* No `.tplr` (tModLoader) support; those files are a different, older format.
* One character at a time — no side-by-side transfer pane.
* Journey-mode creative powers are preserved but not editable; research is read-only.
* Editing a character that the game currently has open will be overwritten by the game.
* Sprites need an installed copy of Terraria. It is looked for in the standard Steam, GOG
  and tModLoader locations; set `TFORGE_CONTENT=/path/to/Content/Images` if yours is
  somewhere else. The Display panel has a toggle if you prefer plain tiles.

## Documentation

* `docs/LEARNING.md` — how the code works, written for someone who wants to read or change
  it: the crypto, the parser, the round-trip proof, the UI model, and a few exercises.

//! Item / prefix / buff metadata for terra-forge.
//!
//! The database is embedded at build time from `data/items.json`, which is
//! generated by merging a 1.4.4.9 metadata snapshot (max stack, rarity, tags,
//! research goals) with 1.4.5.8 item IDs and names extracted from the player's
//! own install. Items newer than the snapshot get `estimated = true` and a
//! permissive stack cap; the GUI marks them so the user knows why.

use std::collections::HashMap;
use std::sync::OnceLock;

use serde::Deserialize;

pub mod sprites;

pub const DB_JSON: &str = include_str!("../data/items.json");

#[derive(Debug, Clone, Deserialize)]
pub struct Item {
    pub id: i32,
    pub pid: String,
    pub name: String,
    pub max_stack: i32,
    pub rarity: i32,
    pub tags: u32,
    pub research_goal: i32,
    pub damage: i32,
    pub defense: i32,
    pub estimated: bool,
}

/// Category bit positions, matching `tags` in the embedded database.
pub const TAG_NAMES: [&str; 25] = [
    "Melee",
    "Ranged",
    "Magic",
    "Sentry",
    "Summon",
    "HeadSlot",
    "BodySlot",
    "LegsSlot",
    "Accessory",
    "Vanity",
    "Hook",
    "Mount",
    "Minecart",
    "LightPet",
    "VanityPet",
    "Kite",
    "Drill",
    "Fish",
    "FishingCrate",
    "Ammo",
    "Tile",
    "Wall",
    "Painting",
    "Consumable",
    "Material",
];

pub fn tag_bit(name: &str) -> u32 {
    TAG_NAMES
        .iter()
        .position(|t| *t == name)
        .map(|i| 1u32 << i)
        .unwrap_or(0)
}

#[derive(Debug, Clone, Deserialize)]
pub struct Buff {
    pub id: i32,
    pub name: String,
    pub desc: String,
    pub debuff: bool,
}

#[derive(Debug, Clone, Deserialize)]
pub struct Prefix {
    pub id: u8,
    pub name: String,
}

#[derive(Debug)]
pub struct ItemDb {
    pub game_version: String,
    pub items: Vec<Item>,
    pub buffs: Vec<Buff>,
    pub prefixes: Vec<Prefix>,
    by_pid: HashMap<String, usize>,
}

#[derive(Deserialize)]
struct RawDb {
    game_version: String,
    items: Vec<[serde_json::Value; 10]>,
    prefixes: Vec<[serde_json::Value; 2]>,
    buffs: Vec<[serde_json::Value; 4]>,
}

impl ItemDb {
    fn build() -> Self {
        let raw: RawDb = serde_json::from_str(DB_JSON).expect("embedded items.json is malformed");
        let mut items = Vec::with_capacity(raw.items.len());
        let mut by_pid = HashMap::new();
        for (idx, r) in raw.items.iter().enumerate() {
            let it = Item {
                id: r[0].as_i64().unwrap_or(0) as i32,
                pid: r[1].as_str().unwrap_or("").to_string(),
                name: r[2].as_str().unwrap_or("").to_string(),
                max_stack: r[3].as_i64().unwrap_or(1) as i32,
                rarity: r[4].as_i64().unwrap_or(0) as i32,
                tags: r[5].as_u64().unwrap_or(0) as u32,
                research_goal: r[6].as_i64().unwrap_or(0) as i32,
                damage: r[7].as_i64().unwrap_or(-1) as i32,
                defense: r[8].as_i64().unwrap_or(0) as i32,
                estimated: r[9].as_u64().unwrap_or(0) != 0,
            };
            if !it.pid.is_empty() {
                by_pid.insert(it.pid.clone(), idx);
            }
            items.push(it);
        }
        let prefixes = raw
            .prefixes
            .iter()
            .map(|p| Prefix {
                id: p[0].as_u64().unwrap_or(0) as u8,
                name: p[1].as_str().unwrap_or("").to_string(),
            })
            .collect();
        let buffs = raw
            .buffs
            .iter()
            .map(|b| Buff {
                id: b[0].as_i64().unwrap_or(0) as i32,
                name: b[1].as_str().unwrap_or("").to_string(),
                desc: b[2].as_str().unwrap_or("").to_string(),
                debuff: b[3].as_bool().unwrap_or(false),
            })
            .collect();
        Self {
            game_version: raw.game_version,
            items,
            prefixes,
            buffs,
            by_pid,
        }
    }

    /// The process-wide embedded database (parsed once).
    pub fn embedded() -> &'static ItemDb {
        static DB: OnceLock<ItemDb> = OnceLock::new();
        DB.get_or_init(ItemDb::build)
    }

    pub fn by_id(&self, id: i32) -> Option<&Item> {
        if id <= 0 {
            return None;
        }
        self.items.get(id as usize)
    }

    pub fn by_pid(&self, pid: &str) -> Option<&Item> {
        self.by_pid.get(pid).and_then(|i| self.items.get(*i))
    }

    pub fn display_name(&self, id: i32) -> String {
        if let Some(it) = self.by_id(id).filter(|it| !it.name.is_empty()) {
            it.name.clone()
        } else {
            format!("Item #{id}")
        }
    }

    pub fn max_stack(&self, id: i32) -> i32 {
        self.by_id(id).map(|i| i.max_stack).unwrap_or(1).max(1)
    }

    pub fn prefix_name(&self, id: u8) -> Option<&str> {
        self.prefixes
            .iter()
            .find(|p| p.id == id)
            .map(|p| p.name.as_str())
    }

    /// Fuzzy search over names/ids, optionally restricted to items matching any
    /// bit in `tag_mask` (0 = no filter). Empty query returns the whole (filtered)
    /// catalogue in id order.
    pub fn search(&self, query: &str, tag_mask: u32) -> Vec<&Item> {
        let q = query.trim().to_lowercase();
        let mut hits: Vec<(i32, &Item)> = Vec::new();
        for it in &self.items {
            if it.id == 0 || it.name.is_empty() {
                continue;
            }
            if tag_mask != 0 && it.tags & tag_mask == 0 {
                continue;
            }
            let score = if q.is_empty() {
                Some(0)
            } else {
                match_score(&q, it)
            };
            if let Some(s) = score {
                hits.push((s, it));
            }
        }
        hits.sort_by(|a, b| {
            a.0.cmp(&b.0)
                .then_with(|| b.1.rarity.cmp(&a.1.rarity))
                .then_with(|| a.1.id.cmp(&b.1.id))
        });
        hits.into_iter().map(|(_, it)| it).collect()
    }
}

/// Lower is better. Exact/prefix matches beat scattered subsequences.
fn match_score(q: &str, it: &Item) -> Option<i32> {
    let name = it.name.to_lowercase();
    if name == q {
        return Some(0);
    }
    if name.starts_with(q) {
        return Some(10 + name.len() as i32 / 4);
    }
    if let Some(pos) = name.find(q) {
        return Some(100 + pos as i32 * 2);
    }
    if let Ok(n) = q.parse::<i32>() {
        if it.id == n {
            return Some(1);
        }
    }
    if it.pid.to_lowercase().contains(q) {
        return Some(200);
    }
    // subsequence match with gap penalty
    let mut last = None;
    let mut gaps = 0i32;
    let chars: Vec<char> = name.chars().collect();
    for qc in q.chars() {
        let start = last.map(|i: usize| i + 1).unwrap_or(0);
        let found = chars[start..]
            .iter()
            .position(|c| *c == qc)
            .map(|i| i + start);
        let i = found?;
        if let Some(l) = last {
            gaps += (i - l - 1) as i32;
        }
        last = Some(i);
    }
    Some(300 + gaps)
}

//! Terraria item sprites, read straight out of the installed game.
//!
//! # Why this is possible at all
//!
//! Terraria ships one encrypted-at-rest-but-not-encrypted file per item:
//! `Content/Images/Item_<id>.xnb`. An `.xnb` is an XNA content container:
//!
//! ```text
//! 'X' 'N' 'B' 'w'      platform (w = Windows)
//! u8  version          always 5 for Terraria
//! u8  flags            0x80 = LZX-compressed, 0x01 = HiDef
//! u32 file size
//! u32 decompressed size        (only when compressed)
//! ...   payload
//! ```
//!
//! Compressed payloads are LZX with a *chunk framing* on top that is not part of
//! the LZX spec: each 32 KiB chunk is preceded by a two-byte big-endian length,
//! and chunks whose first byte is `0xFF` also carry the uncompressed length:
//!
//! ```text
//! 0xFF  be16 uncompressed  be16 compressed  <compressed bytes>
//! be16 compressed                          <compressed bytes>
//! ```
//!
//! After decompression the payload is the usual XNB object graph: a list of type
//! readers, a shared-resource count, a type-reader index, then the `Texture2D`:
//! surface format, width, height, mip count, data size, data.
//!
//! Terraria uses surface format 0 (straight RGBA8, one mip), which is why the
//! pixel data can be handed to the GPU with no conversion.
//!
//! # Cost
//!
//! All 6,134 vanilla item textures decode in ~0.3 s single-threaded, roughly
//! 0.05 ms per item. That makes decoding on demand (when a slot first becomes
//! visible) cheaper than shipping a prebuilt atlas, and it means sprites always
//! match the installed game version.

use std::path::PathBuf;

use lzxd::{Lzxd, WindowSize};

#[derive(Debug, thiserror::Error)]
pub enum SpriteError {
    #[error("not an XNB file")]
    NotXnb,
    #[error("unsupported XNB version {0}")]
    UnsupportedVersion(u8),
    #[error("LZX decompression failed: {0}")]
    Lzx(String),
    #[error("malformed payload at offset {0}")]
    Malformed(usize),
    #[error("unsupported texture (surface format {0}, {1}x{2}, {3} bytes)")]
    UnsupportedTexture(i32, u32, u32, u32),
    #[error("read {path}: {source}")]
    Io {
        path: String,
        source: std::io::Error,
    },
}

/// A decoded item texture: straight (non-premultiplied) RGBA8, row-major.
#[derive(Clone)]
pub struct Sprite {
    pub width: u32,
    pub height: u32,
    pub rgba: Vec<u8>,
}

impl Sprite {
    /// Longest side, used to decide whether the sprite needs shrinking.
    pub fn longest_side(&self) -> u32 {
        self.width.max(self.height)
    }

    /// How many animation frames are stacked vertically in this texture.
    ///
    /// Terraria stores animated item art (souls, pets, banners, some critters)
    /// as a *vertical strip* inside one `Item_<id>.xnb`: the file for a 4-frame
    /// soul is 22 x 88. Drawing the whole strip shrinks the item to a quarter of
    /// its size, so the UI needs to know where the first frame ends. The only
    /// reliable signal is geometry — frame height equals the texture width — so
    /// a strip is recognised when the height is an exact multiple of the width.
    pub fn frames(&self) -> u32 {
        if self.width > 0 && self.height > self.width && self.height.is_multiple_of(self.width) {
            self.height / self.width
        } else {
            1
        }
    }

    /// Height of a single frame in pixels (the texture height for still art).
    pub fn frame_height(&self) -> u32 {
        self.height / self.frames()
    }

    /// Size in bytes of the RGBA buffer (for cache accounting).
    pub fn bytes(&self) -> usize {
        self.rgba.len()
    }
}

// ---------------------------------------------------------------- XNB reader

struct Cursor<'a> {
    b: &'a [u8],
    p: usize,
}

impl<'a> Cursor<'a> {
    fn u8(&mut self) -> Result<u8, SpriteError> {
        let v = *self.b.get(self.p).ok_or(SpriteError::Malformed(self.p))?;
        self.p += 1;
        Ok(v)
    }

    fn take(&mut self, n: usize) -> Result<&'a [u8], SpriteError> {
        let end = self
            .p
            .checked_add(n)
            .ok_or(SpriteError::Malformed(self.p))?;
        let s = self
            .b
            .get(self.p..end)
            .ok_or(SpriteError::Malformed(self.p))?;
        self.p = end;
        Ok(s)
    }

    fn i32(&mut self) -> Result<i32, SpriteError> {
        let s = self.take(4)?;
        Ok(i32::from_le_bytes([s[0], s[1], s[2], s[3]]))
    }

    fn u32(&mut self) -> Result<u32, SpriteError> {
        Ok(self.i32()? as u32)
    }

    /// .NET 7-bit encoded integer (used for counts and string lengths).
    fn varint(&mut self) -> Result<usize, SpriteError> {
        let mut value = 0usize;
        let mut shift = 0;
        loop {
            let byte = self.u8()?;
            value |= ((byte & 0x7F) as usize) << shift;
            if byte & 0x80 == 0 {
                return Ok(value);
            }
            shift += 7;
            if shift > 63 {
                return Err(SpriteError::Malformed(self.p));
            }
        }
    }

    fn string(&mut self) -> Result<&'a [u8], SpriteError> {
        let len = self.varint()?;
        self.take(len)
    }
}

/// Undo the XNB chunk framing and LZX-compress the payload.
fn decompress_lzx(payload: &[u8], total: usize) -> Result<Vec<u8>, SpriteError> {
    let mut dec = Lzxd::new(WindowSize::KB64);
    let mut out = Vec::with_capacity(total);
    let mut p = 0usize;

    while out.len() < total {
        let first = *payload.get(p).ok_or(SpriteError::Malformed(p))?;
        let (compressed, uncompressed) = if first == 0xFF {
            let sizes = payload.get(p + 1..p + 5).ok_or(SpriteError::Malformed(p))?;
            let uncompressed = u16::from_be_bytes([sizes[0], sizes[1]]) as usize;
            let compressed = u16::from_be_bytes([sizes[2], sizes[3]]) as usize;
            p += 5;
            (compressed, uncompressed)
        } else {
            let sizes = payload.get(p..p + 2).ok_or(SpriteError::Malformed(p))?;
            let compressed = u16::from_be_bytes([sizes[0], sizes[1]]) as usize;
            p += 2;
            (compressed, (total - out.len()).min(32 * 1024))
        };
        if compressed == 0 {
            return Err(SpriteError::Malformed(p));
        }
        let chunk = payload
            .get(p..p + compressed)
            .ok_or(SpriteError::Malformed(p))?;
        p += compressed;
        let decoded = dec
            .decompress_next(chunk, uncompressed)
            .map_err(|e| SpriteError::Lzx(e.to_string()))?;
        out.extend_from_slice(decoded);
    }
    Ok(out)
}

/// Decode one `.xnb` texture file into RGBA8.
pub fn decode_xnb(data: &[u8]) -> Result<Sprite, SpriteError> {
    if data.len() < 10 || &data[0..4] != b"XNBw" && &data[0..4] != b"XNBx" {
        return Err(SpriteError::NotXnb);
    }
    let version = data[4];
    if version != 5 {
        return Err(SpriteError::UnsupportedVersion(version));
    }
    let flags = data[5];
    let compressed = flags & 0x80 != 0;

    let body: Vec<u8> = if compressed {
        let size_bytes = data.get(10..14).ok_or(SpriteError::Malformed(10))?;
        let total = u32::from_le_bytes([size_bytes[0], size_bytes[1], size_bytes[2], size_bytes[3]])
            as usize;
        decompress_lzx(&data[14..], total)?
    } else {
        data[10..].to_vec()
    };

    let mut c = Cursor { b: &body, p: 0 };

    // Type reader table, then the shared resource count, then the object.
    let readers = c.varint()?;
    for _ in 0..readers {
        c.string()?;
        c.i32()?;
    }
    let _shared = c.varint()?;
    let _type_index = c.varint()?;

    let surface = c.i32()?;
    let width = c.u32()?;
    let height = c.u32()?;
    let _mips = c.u32()?;
    let data_size = c.u32()?;

    // Surface format 0 is Color (RGBA8) and Terraria always ships one mip.
    if surface != 0 || width == 0 || height == 0 || data_size != width * height * 4 {
        return Err(SpriteError::UnsupportedTexture(
            surface, width, height, data_size,
        ));
    }
    let rgba = c.take(data_size as usize)?.to_vec();
    Ok(Sprite {
        width,
        height,
        rgba,
    })
}

/// Decode one item's sprite by id. Returns `Ok(None)` when the file is absent,
/// which is normal: not every id has artwork, and the game may not be installed.
pub fn load_item_sprite(id: i32) -> Result<Option<Sprite>, SpriteError> {
    if id <= 0 {
        return Ok(None);
    }
    let Some(dir) = item_dir() else {
        return Ok(None);
    };
    let path = dir.join(format!("Item_{id}.xnb"));

        Ok(data) => decode_xnb(&data).map(Some),

        Err(source) => Err(SpriteError::Io {
            path: path.display().to_string(),
            source,
        }),
    }
}

//! AES-128-CBC framing for Terraria `.plr` / `.tplr` files.
//!
//! The key and IV are the same 16 bytes: the UTF-16LE encoding of `h3y_gUyZ`.
//! The whole payload is padded with PKCS#7 and encrypted as a single stream.

pub const KEY_BYTES: [u8; 16] = [
    0x68, 0x00, 0x33, 0x00, 0x79, 0x00, 0x5F, 0x00, 0x67, 0x00, 0x55, 0x00, 0x79, 0x00, 0x5A, 0x00,
];

pub const BLOCK: usize = 16;

use aes::Aes128;
use cbc::cipher::{block_padding::Pkcs7, BlockDecryptMut, BlockEncryptMut, KeyIvInit};

type Enc = cbc::Encryptor<Aes128>;
type Dec = cbc::Decryptor<Aes128>;

#[derive(Debug, thiserror::Error)]
pub enum CryptoError {
    #[error("file is not a whole number of AES blocks ({0} bytes)")]
    NotBlockAligned(usize),
    #[error("decryption failed (bad padding)")]
    BadPadding,
    #[error("encryption failed")]
    Encrypt,
}

/// Decrypt a `.plr` byte stream, stripping PKCS#7 padding.
pub fn decrypt(data: &[u8]) -> Result<Vec<u8>, CryptoError> {
    if data.is_empty() || !data.len().is_multiple_of(BLOCK) {
        return Err(CryptoError::NotBlockAligned(data.len()));
    }
    let mut buf = data.to_vec();
    let plain = Dec::new(&KEY_BYTES.into(), &KEY_BYTES.into())
        .decrypt_padded_mut::<Pkcs7>(&mut buf)
        .map_err(|_| CryptoError::BadPadding)?;
    Ok(plain.to_vec())
}

/// Encrypt a payload, applying PKCS#7 padding.
pub fn encrypt(plain: &[u8]) -> Result<Vec<u8>, CryptoError> {
    let mut buf = vec![0u8; plain.len() + BLOCK];
    buf[..plain.len()].copy_from_slice(plain);
    let ct = Enc::new(&KEY_BYTES.into(), &KEY_BYTES.into())
        .encrypt_padded_mut::<Pkcs7>(&mut buf, plain.len())
        .map_err(|_| CryptoError::Encrypt)?;
    Ok(ct.to_vec())
}

//! C# `BinaryReader` / `BinaryWriter` compatible primitives, little-endian.
//!
//! Strings use the same encoding as .NET's `BinaryWriter.Write(string)`:
//! a 7-bit encoded byte-length prefix followed by UTF-8 bytes.

#[derive(Debug, thiserror::Error)]
pub enum IoError {
    #[error("unexpected end of data at offset {offset} (needed {needed} more bytes)")]
    Eof { offset: usize, needed: usize },
    #[error("string length {0} exceeds remaining data")]
    BadStringLen(u64),
    #[error("invalid UTF-8 at offset {0}")]
    Utf8(usize),
}

pub struct Reader<'a> {
    data: &'a [u8],
    pos: usize,
}

impl<'a> Reader<'a> {
    pub fn new(data: &'a [u8]) -> Self {
        Self { data, pos: 0 }
    }

    pub fn pos(&self) -> usize {
        self.pos
    }

    pub fn set_pos(&mut self, pos: usize) {
        self.pos = pos;
    }

    pub fn remaining(&self) -> usize {
        self.data.len().saturating_sub(self.pos)
    }

    pub fn at_end(&self) -> bool {
        self.pos >= self.data.len()
    }

    pub fn take(&mut self, n: usize) -> Result<&'a [u8], IoError> {
        if self.remaining() < n {
            return Err(IoError::Eof {
                offset: self.pos,
                needed: n,
            });
        }
        let s = &self.data[self.pos..self.pos + n];
        self.pos += n;
        Ok(s)
    }

    pub fn u8(&mut self) -> Result<u8, IoError> {
        Ok(self.take(1)?[0])
    }

    pub fn bool(&mut self) -> Result<bool, IoError> {
        Ok(self.u8()? != 0)
    }

    pub fn i16(&mut self) -> Result<i16, IoError> {
        let b = self.take(2)?;
        Ok(i16::from_le_bytes([b[0], b[1]]))
    }

    pub fn u16(&mut self) -> Result<u16, IoError> {
        let b = self.take(2)?;
        Ok(u16::from_le_bytes([b[0], b[1]]))
    }

    pub fn i32(&mut self) -> Result<i32, IoError> {
        let b = self.take(4)?;
        Ok(i32::from_le_bytes([b[0], b[1], b[2], b[3]]))
    }

    pub fn u32(&mut self) -> Result<u32, IoError> {
        Ok(self.i32()? as u32)
    }

    pub fn f32(&mut self) -> Result<f32, IoError> {
        Ok(f32::from_bits(self.u32()?))
    }

    /// .NET `BinaryReader.ReadString`: 7-bit length prefix + UTF-8.
    pub fn string(&mut self) -> Result<String, IoError> {
        let start = self.pos;
        let mut len: u64 = 0;
        let mut shift = 0;
        loop {
            let b = self.u8()?;
            len |= ((b & 0x7F) as u64) << shift;
            if b & 0x80 == 0 {
                break;
            }
            shift += 7;
            if shift > 63 {
                return Err(IoError::BadStringLen(len));
            }
        }
        if len as usize > self.remaining() {
            return Err(IoError::BadStringLen(len));
        }
        let bytes = self.take(len as usize)?;
        std::str::from_utf8(bytes)
            .map(|s| s.to_owned())
            .map_err(|_| IoError::Utf8(start))
    }

    pub fn rest(&mut self) -> &'a [u8] {
        let s = &self.data[self.pos..];
        self.pos = self.data.len();
        s
    }
}

#[derive(Default)]
pub struct Writer {
    buf: Vec<u8>,
}

impl Writer {
    pub fn new() -> Self {
        Self { buf: Vec::new() }
    }

    pub fn len(&self) -> usize {
        self.buf.len()
    }

    pub fn is_empty(&self) -> bool {
        self.buf.is_empty()
    }

    pub fn into_bytes(self) -> Vec<u8> {
        self.buf
    }

    pub fn bytes(&self) -> &[u8] {
        &self.buf
    }

    pub fn raw(&mut self, b: &[u8]) {
        self.buf.extend_from_slice(b);
    }

    pub fn u8(&mut self, v: u8) {
        self.buf.push(v);
    }

    pub fn bool(&mut self, v: bool) {
        self.buf.push(v as u8);
    }

    pub fn i16(&mut self, v: i16) {
        self.buf.extend_from_slice(&v.to_le_bytes());
    }

    pub fn i32(&mut self, v: i32) {
        self.buf.extend_from_slice(&v.to_le_bytes());
    }

    pub fn u32(&mut self, v: u32) {
        self.buf.extend_from_slice(&v.to_le_bytes());
    }

    pub fn f32(&mut self, v: f32) {
        self.buf.extend_from_slice(&v.to_le_bytes());
    }

    pub fn string(&mut self, s: &str) {
        let b = s.as_bytes();
        let mut len = b.len() as u64;
        loop {
            let byte = (len & 0x7F) as u8;
            len >>= 7;
            if len == 0 {
                self.buf.push(byte);
                break;
            }
            self.buf.push(byte | 0x80);
        }
        self.buf.extend_from_slice(b);
    }
}

//! File-level operations: load, verify and save with backup.

use std::fs;
use std::io;
use std::path::{Path, PathBuf};

use crate::crypto;
use crate::plr::PlayerFile;

#[derive(Debug, thiserror::Error)]
pub enum FileError {
    #[error("read {path}: {source}")]
    Read { path: String, source: io::Error },
    #[error("write {path}: {source}")]
    Write { path: String, source: io::Error },
    #[error(transparent)]
    Crypto(#[from] crypto::CryptoError),
    #[error(transparent)]
    Parse(#[from] crate::plr::PlrError),
    #[error("refusing to write: round-trip check failed at byte {0} — file left untouched")]
    RoundTripMismatch(usize),
}

/// Read + decrypt + parse a `.plr` file.
pub fn load(path: &Path) -> Result<PlayerFile, FileError> {
    let raw = fs::read(path).map_err(|e| FileError::Read {
        path: path.display().to_string(),
        source: e,
    })?;
    let plain = crypto::decrypt(&raw)?;
    Ok(PlayerFile::parse(&plain)?)
}

/// Verify that a file survives decrypt -> parse -> serialise -> encrypt unchanged.
/// Returns the offset of the first differing byte on failure.
pub fn verify_roundtrip(path: &Path) -> Result<(), FileError> {
    let raw = fs::read(path).map_err(|e| FileError::Read {
        path: path.display().to_string(),
        source: e,
    })?;
    let plain = crypto::decrypt(&raw)?;
    let player = PlayerFile::parse(&plain)?;
    let re_plain = player.serialize();
    if re_plain != plain {
        let at = first_diff(&re_plain, &plain);
        return Err(FileError::RoundTripMismatch(at));
    }
    Ok(())
}

fn first_diff(a: &[u8], b: &[u8]) -> usize {
    a.iter()
        .zip(b.iter())
        .position(|(x, y)| x != y)
        .unwrap_or(a.len().min(b.len()))
}

/// Path of the backup file used before overwriting (`Name.plr` -> `Name.plr.bak`).
pub fn backup_path(path: &Path) -> PathBuf {
    let mut s = path.as_os_str().to_os_string();
    s.push(".bak");
    PathBuf::from(s)
}

/// Save a player file, first copying the existing file to `<name>.plr.bak`.
///
/// The payload is re-parsed and compared before anything is written; if the
/// serialiser cannot reproduce the file we loaded, nothing is written at all.
pub fn save_with_backup(path: &Path, player: &PlayerFile) -> Result<PathBuf, FileError> {
    let plain = player.serialize();
    let encrypted = crypto::encrypt(&plain)?;

    let mut backup = None;
    if path.exists() {
        let existing = fs::read(path).map_err(|e| FileError::Read {
            path: path.display().to_string(),
            source: e,
        })?;
        let bak = backup_path(path);
        fs::write(&bak, &existing).map_err(|e| FileError::Write {
            path: bak.display().to_string(),
            source: e,
        })?;
        backup = Some(bak);
    }

    let tmp = path.with_extension("plr.tmp");
    fs::write(&tmp, &encrypted).map_err(|e| FileError::Write {
        path: tmp.display().to_string(),
        source: e,
    })?;
    // Read back what we just wrote: if the game could not load it, we should not
    // have replaced the original.
    let check = fs::read(&tmp).map_err(|e| FileError::Read {
        path: tmp.display().to_string(),
        source: e,
    })?;
    if crypto::decrypt(&check)? != plain {
        let _ = fs::remove_file(&tmp);
        return Err(FileError::RoundTripMismatch(0));
    }
    fs::rename(&tmp, path).map_err(|e| FileError::Write {
        path: path.display().to_string(),
        source: e,
    })?;
    Ok(backup.unwrap_or_default())
}

/// Standard player directories, most-likely-first.

        .map(PathBuf::from)
        .unwrap_or_default();

            if p.is_dir() {

        }
    }
    dirs.push(home.join(".local/share/Terraria/tModLoader/Players"));

/// All `.plr` files across the standard directories, sorted by name.
pub fn discover_players() -> Vec<PathBuf> {
    let mut out = Vec::new();
    for d in player_dirs() {
        if let Ok(entries) = fs::read_dir(&d) {
            for e in entries.flatten() {
                let p = e.path();
                if p.extension().is_some_and(|x| x.eq_ignore_ascii_case("plr")) {
                    out.push(p);
                }
            }
        }
    }
    out.sort();
    out.dedup();
    out
}

//! Terraria player file (`.plr`) binary format.
//!
//! Layout reconstructed from real 1.4.4.9 (279) and 1.4.5.8 (326) files and
//! validated by byte-identical round-trip. Field order follows
//! `Player.SavePlayer`, with every field gated on the file's `version` int.
//!
//! Anything after the last field we understand is preserved verbatim in
//! [`PlayerFile::trailing`], so files written by a newer patch than this crate
//! knows about still round-trip losslessly.

use crate::cursor::{IoError, Reader, Writer};

pub const MAGIC_A: u32 = 1_869_374_834; // "relo"
pub const MAGIC_B: u32 = 56_846_695; // "gic" + file type 3

/// Format versions we have verified against real files.
pub const VER_1_4_0: i32 = 225;
pub const VER_1_4_3: i32 = 248;
pub const VER_1_4_4_0: i32 = 269;
pub const VER_1_4_4_9: i32 = 279;
pub const VER_1_4_5_0: i32 = 315;
pub const VER_1_4_5_7: i32 = 325;
pub const VER_1_4_5_8: i32 = 326;

#[derive(Debug, thiserror::Error)]
pub enum PlrError {
    #[error(transparent)]
    Io(#[from] IoError),
    #[error("not a Terraria player file (bad magic {0:#x}/{1:#x})")]
    BadMagic(u32, u32),
    #[error("unsupported pre-1.4 player format version {0}")]
    UnsupportedVersion(i32),
    #[error("player version {0} is newer than this build understands; trailing bytes were preserved but fields may be stale")]
    NewerVersion(i32),
}

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct Slot {
    /// Item netID, 0 = empty.
    pub net_id: i32,
    /// Stack size (only stored for stackable containers).
    pub stack: i32,
    pub prefix: u8,
    pub favorited: bool,
}

impl Slot {
    pub fn empty() -> Self {
        Self::default()
    }

    pub fn is_empty(&self) -> bool {
        self.net_id == 0
    }

    pub fn new(net_id: i32, stack: i32, prefix: u8) -> Self {
        Self {
            net_id,
            stack,
            prefix,
            favorited: false,
        }
    }
}

/// How a given container encodes its slots on disk.
#[derive(Debug, Clone, Copy)]
struct SlotKind {
    /// Stack size is stored as an i32 after the netID.
    multi: bool,
    /// Favorited flag is stored after the prefix, once version >= fav_min (0 = never).
    fav_min: i32,
}

const K_INVENTORY: SlotKind = SlotKind {
    multi: true,
    fav_min: 145,
};
const K_COIN_AMMO: SlotKind = SlotKind {
    multi: true,
    fav_min: 145,
};
const K_EQUIP: SlotKind = SlotKind {
    multi: false,
    fav_min: 0,
};
const K_BANK: SlotKind = SlotKind {
    multi: true,
    fav_min: 0,
};
const K_VOID: SlotKind = SlotKind {
    multi: true,
    fav_min: 269,
};
const K_TEMP: SlotKind = SlotKind {
    multi: true,
    fav_min: 0,
};
const K_LOADOUT_ACTIVE: SlotKind = SlotKind {
    multi: false,
    fav_min: 325,
};
const K_LOADOUT_STORED: SlotKind = SlotKind {
    multi: true,
    fav_min: 325,
};

fn read_slot(r: &mut Reader<'_>, v: i32, k: SlotKind) -> Result<Slot, IoError> {
    let net_id = r.i32()?;
    let stack = if k.multi { r.i32()? } else { 1 };
    let prefix = r.u8()?;
    let favorited = if k.fav_min > 0 && v >= k.fav_min {
        r.bool()?
    } else {
        false
    };
    Ok(Slot {
        net_id,
        stack,
        prefix,
        favorited,
    })
}

fn write_slot(w: &mut Writer, v: i32, k: SlotKind, s: &Slot) {
    w.i32(s.net_id);
    if k.multi {
        w.i32(s.stack);
    }
    w.u8(s.prefix);
    if k.fav_min > 0 && v >= k.fav_min {
        w.bool(s.favorited);
    }
}

fn read_slots(r: &mut Reader<'_>, v: i32, k: SlotKind, n: usize) -> Result<Vec<Slot>, IoError> {
    (0..n).map(|_| read_slot(r, v, k)).collect()
}

fn write_slots(w: &mut Writer, v: i32, k: SlotKind, slots: &[Slot]) {
    for s in slots {
        write_slot(w, v, k, s);
    }
}

/// One of the four equipment loadouts (1.4.4+).
#[derive(Debug, Clone, Default)]
pub struct Loadout {
    /// 10 equipment slots: 3 armour + 7 accessories (the 8th is the demon-heart slot).
    pub items: Vec<Slot>,
    /// 10 vanity/social slots.
    pub social: Vec<Slot>,
    /// 10 dye slots.
    pub dyes: Vec<Slot>,
    /// 10 "hide visual" toggles.
    pub hide: Vec<bool>,
}

impl Loadout {
    fn new() -> Self {
        Self {
            items: vec![Slot::empty(); 10],
            social: vec![Slot::empty(); 10],
            dyes: vec![Slot::empty(); 10],
            hide: vec![false; 10],
        }
    }

    /// The active loadout stored inline with the player does *not* carry its own
    /// hide-visual flags (those live in `PlayerFile::hide_visual`); each of the
    /// three stored loadouts carries 10 extra hide bytes.
    fn read(r: &mut Reader<'_>, v: i32, k: SlotKind) -> Result<Self, IoError> {
        let items = read_slots(r, v, k, 10)?;
        let social = read_slots(r, v, k, 10)?;
        let dyes = read_slots(r, v, k, 10)?;
        let hide = if k.multi {
            (0..10).map(|_| r.bool()).collect::<Result<_, _>>()?
        } else {
            vec![false; 10]
        };
        Ok(Self {
            items,
            social,
            dyes,
            hide,
        })
    }

    fn write(&self, w: &mut Writer, v: i32, k: SlotKind) {
        let kk = if k.multi {
            K_LOADOUT_STORED
        } else {
            K_LOADOUT_ACTIVE
        };
        write_slots(w, v, kk, &self.items);
        write_slots(w, v, kk, &self.social);
        write_slots(w, v, kk, &self.dyes);
        if k.multi {
            for h in &self.hide {
                w.bool(*h);
            }
        }
    }
}

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct Color {
    pub r: u8,
    pub g: u8,
    pub b: u8,
}

impl Color {
    /// Terraria stores colours as `r << 16 | g << 8 | b`.
    pub fn to_u32(self) -> u32 {
        (self.r as u32) << 16 | (self.g as u32) << 8 | self.b as u32
    }

    pub fn from_u32(v: u32) -> Self {
        Self {
            r: (v >> 16) as u8,
            g: (v >> 8) as u8,
            b: v as u8,
        }
    }
}

    pub fn parse(plain: &[u8]) -> Result<Self, PlrError> {
        let mut r = Reader::new(plain);
        let mut p = Self::new_v326("");

        let v = r.i32()?;
        if v < VER_1_4_0 {
            return Err(PlrError::UnsupportedVersion(v));
        }
        p.version = v;

        let ma = r.u32()?;
        let mb = r.u32()?;
        if ma != MAGIC_A || mb != MAGIC_B {
            return Err(PlrError::BadMagic(ma, mb));
        }
        p.meta_version = r.u32()?;
        p.meta_flags1 = r.u32()?;
        p.meta_flags2 = r.u32()?;

        p.name = r.string()?;
        p.difficulty = r.u8()?;
        p.play_time_l = r.u32()?;
        p.play_time_h = r.u32()?;
        p.hair_style = r.i32()?;
        if v >= 82 {
            p.hair_dye = r.u8()?;
        }
        if v >= VER_1_4_5_0 {
            p.team = r.u8()?;
        }
        if v >= 83 {
            p.hide_visual = r.u8()? as u16;
            if v >= 145 {
                p.hide_visual |= (r.u8()? as u16) << 8;
            }
        }
        if v >= 145 {
            p.hide_misc = r.u8()?;
            p.gender = r.u8()?;
        }
        p.health_now = r.i32()?;
        p.health_max = r.i32()?;
        p.mana_now = r.i32()?;
        p.mana_max = r.i32()?;
        if v >= 145 {
            p.extra_accessory = r.bool()?;
            if v >= 230 {
                p.unlocked_biome_torches = r.bool()?;
                p.using_biome_torches = r.bool()?;
            }
            if v >= 269 {
                p.ate_artisan_bread = r.bool()?;
            }
            if v >= VER_1_4_5_7 {
                p.mystery_flag_1470 = r.bool()?;
            }
            if v >= 269 {
                for f in p.extra_using_flags.iter_mut() {
                    *f = r.bool()?;
                }
            }
            if v >= 184 {
                p.finished_dd2_event = r.bool()?;
            }
            p.tax_money = r.i32()?;
            if v >= 269 {
                p.pve_deaths = r.i32()?;
                p.pvp_deaths = r.i32()?;
            }
        }

        p.hair_color = Color {
            r: r.u8()?,
            g: r.u8()?,
            b: r.u8()?,
        };
        p.skin_color = Color {
            r: r.u8()?,
            g: r.u8()?,
            b: r.u8()?,
        };
        p.eye_color = Color {
            r: r.u8()?,
            g: r.u8()?,
            b: r.u8()?,
        };
        p.shirt_color = Color {
            r: r.u8()?,
            g: r.u8()?,
            b: r.u8()?,
        };
        p.under_color = Color {
            r: r.u8()?,
            g: r.u8()?,
            b: r.u8()?,
        };
        p.pants_color = Color {
            r: r.u8()?,
            g: r.u8()?,
            b: r.u8()?,
        };
        p.shoes_color = Color {
            r: r.u8()?,
            g: r.u8()?,
            b: r.u8()?,
        };

        p.active_loadout = Loadout::read(&mut r, v, K_LOADOUT_ACTIVE)?;
        p.inventory = read_slots(&mut r, v, K_INVENTORY, 50)?;
        p.coins = read_slots(&mut r, v, K_COIN_AMMO, 4)?;
        p.ammo = read_slots(&mut r, v, K_COIN_AMMO, 4)?;

        p.equipment_items = Vec::with_capacity(5);
        p.equipment_dyes = Vec::with_capacity(5);
        for _ in 0..5 {
            p.equipment_items.push(read_slot(&mut r, v, K_EQUIP)?);
            p.equipment_dyes.push(read_slot(&mut r, v, K_EQUIP)?);
        }

        p.bank = read_slots(&mut r, v, K_BANK, 40)?;
        p.safe = read_slots(&mut r, v, K_BANK, 40)?;
        p.forge = read_slots(&mut r, v, K_BANK, 40)?;
        p.void_bag = read_slots(&mut r, v, K_VOID, 40)?;
        if v >= 200 {
            p.void_vault_byte = r.u8()?;
        }

        let n_buffs = if v >= 269 {
            44
        } else if v >= 77 {
            22
        } else {
            10
        };
        p.buffs = (0..n_buffs)
            .map(|_| {
                Ok::<_, IoError>(Buff {
                    id: r.i32()?,
                    time: r.i32()?,
                })
            })
            .collect::<Result<_, _>>()?;

        loop {
            let spawn_x = r.i32()?;
            if spawn_x == -1 {
                break;
            }
            let e = ServerEntry {
                spawn_x,
                spawn_y: r.i32()?,
                address: r.i32()?,
                name: r.string()?,
            };
            p.servers.push(e);
        }

        p.hotbar_locked = r.bool()?;
        if v >= 145 {
            p.hide_info = (0..13).map(|_| r.bool()).collect::<Result<_, _>>()?;
        }
        if v >= 98 {
            p.fishing_quests = r.i32()?;
        }
        if v >= 168 {
            p.dpad_bindings = (0..4).map(|_| r.i32()).collect::<Result<_, _>>()?;
        }
        let n_acc = if v >= 230 {
            12
        } else if v >= 200 {
            11
        } else {
            10
        };
        p.builder_acc = (0..n_acc).map(|_| r.i32()).collect::<Result<_, _>>()?;
        if v >= 184 {
            p.bartender_quests = r.i32()?;
        }
        if v >= 200 {
            p.is_dead = r.bool()?;
            if p.is_dead {
                p.respawn_timer = r.i32()?;
            }
            p.last_time_saved_1 = r.i32()?;
            p.last_time_saved_2 = r.i32()?;
            p.golfer_score = r.i32()?;
        }

        if v >= 200 {
            if v >= VER_1_4_5_0 {
                p.research_mystery_byte = r.u8()?;
            }
            let n = r.i32()?;
            if n < 0 {
                return Err(PlrError::Io(IoError::BadStringLen(n as u64)));
            }
            for _ in 0..n {
                let pid = r.string()?;
                let count = r.i32()?;
                p.research.push((pid, count));
            }

            let mask = r.u8()?;
            p.temp_items = Vec::new();
            for i in 0..4u8 {
                if mask & (1 << i) != 0 {
                    p.temp_items.push(read_slot(&mut r, v, K_TEMP)?);
                } else {
                    p.temp_items.push(Slot::empty());
                }
            }
        }

        if v >= 220 {
            // Creative-power list: a tag byte 1 + power id (i16) + payload, until tag 0.
            loop {
                let tag = r.u8()?;
                if tag == 0 {
                    break;
                }
                let power = r.i16()?;
                let value = match creative_power_payload(power) {
                    CreativePayload::None => CreativeValue::None,
                    CreativePayload::Byte => CreativeValue::Byte(r.u8()?),
                    CreativePayload::Float => CreativeValue::Float(r.f32()?),
                    CreativePayload::Unknown => {
                        return Err(PlrError::Io(IoError::BadStringLen(power as u64)));
                    }
                };
                p.creative_powers.push(CreativePower { id: power, value });
            }
        }
        if v >= 253 {
            p.super_cart_byte = r.u8()?;
        }
        if v >= 269 {
            p.current_loadout = r.i32()?;
            p.stored_loadouts = (0..3)
                .map(|_| Loadout::read(&mut r, v, K_LOADOUT_STORED))
                .collect::<Result<_, _>>()?;
        }
        if v >= VER_1_4_5_0 {
            p.voice_variant = r.u8()?;
            p.voice_pitch_offset = r.i32()?;

            let n = r.i32()?;
            for _ in 0..n.max(0) {
                let id = r.i32()?;
                let count = r.i32()?;
                let prefix = r.u8()?;
                p.pending_refunds.push((id, count, prefix));
            }
            let n = r.i32()?;
            for _ in 0..n.max(0) {
                p.dialogues_seen.push(r.string()?);
            }
        }

        p.trailing = r.rest().to_vec();
        Ok(p)
    }

    pub fn serialize(&self) -> Vec<u8> {
        let v = self.version;
        let mut w = Writer::new();

        w.i32(v);
        w.u32(MAGIC_A);
        w.u32(MAGIC_B);
        w.u32(self.meta_version);
        w.u32(self.meta_flags1);
        w.u32(self.meta_flags2);

        w.string(&self.name);
        w.u8(self.difficulty);
        w.u32(self.play_time_l);
        w.u32(self.play_time_h);
        w.i32(self.hair_style);
        if v >= 82 {
            w.u8(self.hair_dye);
        }
        if v >= VER_1_4_5_0 {
            w.u8(self.team);
        }
        if v >= 83 {
            w.u8(self.hide_visual as u8);
            if v >= 145 {
                w.u8((self.hide_visual >> 8) as u8);
            }
        }
        if v >= 145 {
            w.u8(self.hide_misc);
            w.u8(self.gender);
        }
        w.i32(self.health_now);
        w.i32(self.health_max);
        w.i32(self.mana_now);
        w.i32(self.mana_max);
        if v >= 145 {
            w.bool(self.extra_accessory);
            if v >= 230 {
                w.bool(self.unlocked_biome_torches);
                w.bool(self.using_biome_torches);
            }
            if v >= 269 {
                w.bool(self.ate_artisan_bread);
            }
            if v >= VER_1_4_5_7 {
                w.bool(self.mystery_flag_1470);
            }
            if v >= 269 {
                for f in self.extra_using_flags {
                    w.bool(f);
                }
            }
            if v >= 184 {
                w.bool(self.finished_dd2_event);
            }
            w.i32(self.tax_money);
            if v >= 269 {
                w.i32(self.pve_deaths);
                w.i32(self.pvp_deaths);
            }
        }

        for c in [
            self.hair_color,
            self.skin_color,
            self.eye_color,
            self.shirt_color,
            self.under_color,
            self.pants_color,
            self.shoes_color,
        ] {
            w.u8(c.r);
            w.u8(c.g);
            w.u8(c.b);
        }

        self.active_loadout.write(&mut w, v, K_LOADOUT_ACTIVE);
        write_slots(&mut w, v, K_INVENTORY, &self.inventory);
        write_slots(&mut w, v, K_COIN_AMMO, &self.coins);
        write_slots(&mut w, v, K_COIN_AMMO, &self.ammo);
        for i in 0..5 {
            write_slot(&mut w, v, K_EQUIP, &self.equipment_items[i]);
            write_slot(&mut w, v, K_EQUIP, &self.equipment_dyes[i]);
        }
        write_slots(&mut w, v, K_BANK, &self.bank);
        write_slots(&mut w, v, K_BANK, &self.safe);
        write_slots(&mut w, v, K_BANK, &self.forge);
        write_slots(&mut w, v, K_VOID, &self.void_bag);
        if v >= 200 {
            w.u8(self.void_vault_byte);
        }

        for b in &self.buffs {
            w.i32(b.id);
            w.i32(b.time);
        }
        for s in &self.servers {

            w.i32(s.spawn_y);

                w.u8(self.research_mystery_byte);

            for (pid, count) in &self.research {
                w.string(pid);
                w.i32(*count);

                }
            }

                    write_slot(&mut w, v, K_TEMP, s);
                }
            }
        }

            for cp in &self.creative_powers {
                w.u8(1);
                w.i16(cp.id);
                match cp.value {
                    CreativeValue::None => {}
                    CreativeValue::Byte(b) => w.u8(b),
                    CreativeValue::Float(f) => w.f32(f),
                }
            }
            w.u8(0);
        }

        if v >= 253 {
            w.u8(self.super_cart_byte);
        }
        if v >= 269 {
            w.i32(self.current_loadout);
            for l in &self.stored_loadouts {
                l.write(&mut w, v, K_LOADOUT_STORED);
            }
        }
        if v >= VER_1_4_5_0 {
            w.u8(self.voice_variant);
            w.i32(self.voice_pitch_offset);
            w.i32(self.pending_refunds.len() as i32);
            for (id, count, prefix) in &self.pending_refunds {

                w.i32(*count);
                w.u8(*prefix);

            w.i32(self.dialogues_seen.len() as i32);
            for s in &self.dialogues_seen {
                w.string(s);
            }
        }

        w.raw(&self.trailing);
        w.into_bytes()
    }

//! Turning the flat item database into a browsable, grouped list.
//!
//! `terra-assets` knows about tags (`Melee`, `Tile`, `Accessory`, …) but not
//! about presentation. This module is the presentation layer: it decides which
//! section header a row belongs under, in what order rows appear, and what
//! happens when the user types in the search box.
//!
//! Two modes:
//!
//! * **browsing** (empty query) — items are bucketed into sections, each section
//!   sorted by rarity then name. That is what makes the browser feel organised
//!   instead of being one 6,000-row alphabet.
//! * **searching** (non-empty query) — the ranking from `terra_assets::ItemDb`
//!   is kept verbatim, with no headers, because "why is this first" matters more
//!   than "which section is this in".
//!
//! The result is a flat `Vec<Row>` so the UI can virtualise it: only the rows
//! actually on screen are ever built into widgets.

use std::sync::OnceLock;

use terra_assets::{tag_bit, Item, ItemDb};

/// One line in the browser list.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Row {
    /// A section heading, e.g. "Weapons".
    Header(&'static str),
    /// An item, by numeric id.
    Item(i32),
}

/// A ready-to-render list of rows.
#[derive(Default, Debug)]
pub struct Catalog {
    pub rows: Vec<Row>,
    /// Number of items, excluding headers — what the UI reports as "results".
    pub item_count: usize,
}

impl Catalog {
    /// Build the list for the current query and category filter.
    ///
    /// `cat` is a tag mask; `0` means "no filter / All".
    pub fn build(db: &ItemDb, query: &str, cat: u32) -> Self {
        if query.trim().is_empty() {
            Self::browse(db, cat)
        } else {
            Self::search(db, query.trim(), cat)
        }
    }

    fn search(db: &ItemDb, query: &str, cat: u32) -> Self {
        let mut item_count = 0;
        let rows = db
            .search(query, cat)
            .into_iter()
            .map(|it| {
                item_count += 1;
                Row::Item(it.id)
            })
            .collect();
        Self { rows, item_count }
    }

    fn browse(db: &ItemDb, cat: u32) -> Self {
        let sections: Vec<(&'static str, u32)> = if cat == 0 {
            supersections().to_vec()
        } else {
            subsections(cat)
        };

        // Bucket items per section, "first matching mask wins" so an item that is
        // both Tile and Material shows up once. The final section always has
        // mask 0 and acts as the catch-all.
        let mut buckets: Vec<Vec<&Item>> = vec![Vec::new(); sections.len()];
        for it in &db.items {
            if it.id == 0 || it.name.is_empty() {
                continue;
            }
            if cat != 0 && it.tags & cat == 0 {
                continue;
            }
            let idx = sections
                .iter()
                .position(|(_, mask)| *mask != 0 && it.tags & *mask != 0)
                .unwrap_or(sections.len() - 1);
            buckets[idx].push(it);
        }

        let mut rows = Vec::new();
        let mut item_count = 0;
        for (i, (name, _)) in sections.iter().enumerate() {
            let bucket = &mut buckets[i];
            if bucket.is_empty() {
                continue;
            }
            bucket.sort_by(|a, b| b.rarity.cmp(&a.rarity).then_with(|| a.name.cmp(&b.name)));
            rows.push(Row::Header(name));
            for it in bucket.iter() {
                rows.push(Row::Item(it.id));
                item_count += 1;
            }
        }
        Self { rows, item_count }
    }
}

// ---------------------------------------------------------------- tag masks

// These are functions rather than `const`s because `tag_bit` looks the name up
// in the database's tag list at runtime, and because building them once and
// caching avoids recomputing masks on every frame.

fn cached(slot: &'static OnceLock<u32>, f: impl FnOnce() -> u32) -> u32 {
    *slot.get_or_init(f)
}

macro_rules! mask {
    ($name:ident, $($tag:expr),+ $(,)?) => {
        pub fn $name() -> u32 {
            static CACHE: OnceLock<u32> = OnceLock::new();
            cached(&CACHE, || 0 $(| tag_bit($tag))+)
        }
    };
}

fn supersections() -> &'static [(&'static str, u32)] {
    static CACHE: OnceLock<Vec<(&'static str, u32)>> = OnceLock::new();
    CACHE.get_or_init(|| {

            ("Armor", mask_armour()),
            ("Accessories", mask_accessory()),

            ("Blocks & furniture", mask_blocks() | mask_furniture()),

    })

//! Container plumbing: which part of a player a slot index refers to.
//!
//! The on-disk format stores the same logical thing — an item slot — in a dozen
//! different places, and not all of them are encoded identically. A
//! [`Container`] (`Ct` below) names one such place, and [`container`] /
//! [`container_mut`] hand out the `Vec<Slot>` behind it.
//!
//! The encoding differences live in [`is_multi`] and in `terra_core::plr`:
//!
//! * `multi` containers store an explicit stack count, others implicitly hold 1.
//! * some containers store a "favourited" byte, some do not (version-gated).
//!
//! Keep those two facts in mind whenever you add a container: getting either
//! wrong shifts every following byte and the file stops parsing.

use terra_core::{PlayerFile, Slot};

/// Simple item bags, addressed as one flat vector each.
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Bag {
    Inv,
    Coins,
    Ammo,
    EquipItems,
    EquipDyes,
    Bank,
    Safe,
    Forge,
    Void,
    Temp,
}

/// The three parallel slot rows inside a loadout.
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Group {
    Items,
    Social,
    Dyes,
}

/// One addressable container in a player file.
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Ct {
    Bag(Bag),
    /// Loadout 1, stored inline with the equipment (no hide-flags, no stacks).
    ActiveL(Group),
    /// Loadouts 2..4, stored after `current_loadout` (with hide-flags and stacks).
    StoredL(u8, Group),
}

/// Borrow the slots of a container.
pub fn container(p: &PlayerFile, c: Ct) -> &Vec<Slot> {
    match c {
        Ct::Bag(Bag::Inv) => &p.inventory,
        Ct::Bag(Bag::Coins) => &p.coins,
        Ct::Bag(Bag::Ammo) => &p.ammo,
        Ct::Bag(Bag::EquipItems) => &p.equipment_items,
        Ct::Bag(Bag::EquipDyes) => &p.equipment_dyes,
        Ct::Bag(Bag::Bank) => &p.bank,
        Ct::Bag(Bag::Safe) => &p.safe,
        Ct::Bag(Bag::Forge) => &p.forge,
        Ct::Bag(Bag::Void) => &p.void_bag,
        Ct::Bag(Bag::Temp) => &p.temp_items,
        Ct::ActiveL(Group::Items) => &p.active_loadout.items,
        Ct::ActiveL(Group::Social) => &p.active_loadout.social,
        Ct::ActiveL(Group::Dyes) => &p.active_loadout.dyes,
        Ct::StoredL(n, Group::Items) => &p.stored_loadouts[n as usize].items,
        Ct::StoredL(n, Group::Social) => &p.stored_loadouts[n as usize].social,
        Ct::StoredL(n, Group::Dyes) => &p.stored_loadouts[n as usize].dyes,
    }
}

/// Mutable counterpart of [`container`].
pub fn container_mut(p: &mut PlayerFile, c: Ct) -> &mut Vec<Slot> {
    match c {
        Ct::Bag(Bag::Inv) => &mut p.inventory,
        Ct::Bag(Bag::Coins) => &mut p.coins,
        Ct::Bag(Bag::Ammo) => &mut p.ammo,
        Ct::Bag(Bag::EquipItems) => &mut p.equipment_items,
        Ct::Bag(Bag::EquipDyes) => &mut p.equipment_dyes,
        Ct::Bag(Bag::Bank) => &mut p.bank,
        Ct::Bag(Bag::Safe) => &mut p.safe,
        Ct::Bag(Bag::Forge) => &mut p.forge,
        Ct::Bag(Bag::Void) => &mut p.void_bag,
        Ct::Bag(Bag::Temp) => &mut p.temp_items,
        Ct::ActiveL(Group::Items) => &mut p.active_loadout.items,
        Ct::ActiveL(Group::Social) => &mut p.active_loadout.social,
        Ct::ActiveL(Group::Dyes) => &mut p.active_loadout.dyes,
        Ct::StoredL(n, Group::Items) => &mut p.stored_loadouts[n as usize].items,
        Ct::StoredL(n, Group::Social) => &mut p.stored_loadouts[n as usize].social,
        Ct::StoredL(n, Group::Dyes) => &mut p.stored_loadouts[n as usize].dyes,
    }
}

/// Does this container store a stack count on disk?
///
/// Equipment and the active loadout do not: their slots are netID + prefix
/// (+ favourite). Writing a stack there would corrupt everything after it.
pub fn is_multi(c: Ct) -> bool {
    !matches!(
        c,
        Ct::Bag(Bag::EquipItems) | Ct::Bag(Bag::EquipDyes) | Ct::ActiveL(_)
    )
}

pub fn label(c: Ct) -> &'static str {
    match c {
        Ct::Bag(Bag::Inv) => "Inventory",
        Ct::Bag(Bag::Coins) => "Coins",
        Ct::Bag(Bag::Ammo) => "Ammo",
        Ct::Bag(Bag::EquipItems) => "Equipment",
        Ct::Bag(Bag::EquipDyes) => "Equipment dye",
        Ct::Bag(Bag::Bank) => "Piggy bank",
        Ct::Bag(Bag::Safe) => "Safe",
        Ct::Bag(Bag::Forge) => "Defender's forge",
        Ct::Bag(Bag::Void) => "Void vault",
        Ct::Bag(Bag::Temp) => "Temp",
        Ct::ActiveL(_) => "Loadout 1",
        Ct::StoredL(n, _) => match n {
            0 => "Loadout 2",
            1 => "Loadout 3",
            _ => "Loadout 4",
        },
    }
}

/// A single slot address: which container, which index.
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct SlotRef {
    pub c: Ct,
    pub i: usize,
}

//! terra-forge — a native Linux Terraria character editor.
//!
//! # How the app is put together
//!
//! ```text
//! terra-core    the file format      (bytes in -> PlayerFile -> bytes out)
//! terra-assets  the item catalogue   (embedded JSON + fuzzy search)
//! terra-gui     this crate: state + egui rendering
//! ```
//!
//! The GUI never touches raw bytes. It holds one [`PlayerFile`] in memory and
//! mutates fields on it; saving goes through `terra_core::save_with_backup`,
//! which refuses to write anything it cannot reproduce byte-for-byte.
//!
//! ## The one structural idea worth knowing
//!
//! Everything the user can click on is a [`SlotRef`] — a *container* plus an
//! *index*. Containers are enumerated in [`containers`], which is also where the
//! "does this container store a stack / favourite byte" rules live. Adding a new
//! grid to the UI is therefore: pick a `Ct`, call `section()` with it, done.
//!
//! ## Rendering model
//!
//! Immediate mode: `ui()` runs top to bottom every frame. There is no widget
//! tree to keep in sync — only `App`'s fields are state. Anything transient
//! (a drag in progress) lives in `App` too, because egui forgets it between
//! frames.
//!
//! Panels must be added *before* the central panel or they get no space; that
//! ordering is why `ui()` reads top bar → status bar → side panels → centre.

/// One character found on disk, with the header already decoded so the picker
/// can show the in-game name instead of a file path.
struct PlayerEntry {
    path: PathBuf,
    /// In-game name from the file, or the file stem if it could not be parsed.
    name: String,
    detail: String,
    error: Option<String>,
}

impl PlayerEntry {
    fn probe(path: PathBuf) -> Self {
        let fallback = path
            .file_stem()
            .unwrap_or_default()
            .to_string_lossy()
            .to_string();
        match terra_core::load(&path) {
            Ok(p) => {
                let used = p.inventory.iter().filter(|s| !s.is_empty()).count();
                Self {
                    path,
                    name: p.name.clone(),
                    detail: format!("v{} · {} · {used} items", p.version, p.format_name()),
                    error: None,
                }
            }
            Err(e) => Self {
                path,
                name: fallback,
                detail: String::new(),
                error: Some(e.to_string()),
            },
        }
    }
}

/// An item in flight: either picked from a slot (`from` set) or dragged out of
/// the item browser (`from` is `None`, which turns a drop into a copy).
///
/// `side` records *which character* the source slot belongs to, so the same
/// `Drag` can carry an item from the stash to the hero or the other way round.
#[derive(Clone, Copy)]
struct Drag {
    side: Side,
    from: Option<SlotRef>,
    item: Slot,
}

/// Which character a slot belongs to. The stash is a second, fully editable
/// `PlayerFile`; without this tag a slot reference would be ambiguous.
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
enum Side {
    Primary,
    Stash,
}

/// A second character kept open purely as a source/sink for items.
struct Stash {
    path: PathBuf,
    player: terra_core::PlayerFile,
    dirty: bool,
}

/// A texture drawn on screen, plus the part of it that is one animation frame.
#[derive(Clone)]
struct SpriteTex {
    handle: egui::TextureHandle,
    /// Full texture for still art; the top frame for a vertical strip.
    uv: egui::Rect,
}

impl SpriteTex {
    /// Size of one frame in pixels (not the whole strip).
    fn frame_size(&self) -> Vec2 {
        let size = self.handle.size_vec2();
        Vec2::new(size.x, size.y * self.uv.height())
    }
}

/// Lazily decoded item sprites, held as GPU textures in a small LRU cache.
///
/// Decoding a single `.xnb` costs about 0.05 ms (see `terra_assets::sprites`), so
/// there is no pre-pass: a sprite is decoded the first time a slot showing it is
/// drawn on screen. Only a few hundred are ever live at once, and misses are
/// cached too so a missing file is not re-read every frame.
///
/// The eviction order is true LRU: hits are promoted to the back, so browsing
/// the 6,196-item catalogue cannot evict the sprites of the gear currently on
/// screen. A plain insertion-order queue would do exactly that.
struct SpriteCache {
    /// `None` means "looked for it, there is no sprite for this id".
    textures: std::collections::HashMap<i32, Option<SpriteTex>>,
    order: std::collections::VecDeque<i32>,
    cap: usize,
}

impl SpriteCache {
    fn new(cap: usize) -> Self {
        Self {
            textures: Default::default(),
            order: Default::default(),
            cap,
        }
    }

    fn get(&mut self, ctx: &egui::Context, id: i32) -> Option<SpriteTex> {
        if let Some(hit) = self.textures.get(&id) {
            let hit = hit.clone();
            self.promote(id);
            return hit;
        }
        let entry = match terra_assets::sprites::load_item_sprite(id) {
            Ok(Some(sprite)) => {
                let image = egui::ColorImage::from_rgba_unmultiplied(
                    [sprite.width as usize, sprite.height as usize],
                    &sprite.rgba,
                );
                // Nearest filtering: pixel art must not be blurred.
                let handle =
                    ctx.load_texture(format!("item-{id}"), image, egui::TextureOptions::NEAREST);
                // Animated art is a vertical strip; draw only its first frame,
                // otherwise a four-frame soul is rendered at quarter size.
                let frame_frac = sprite.frame_height() as f32 / sprite.height.max(1) as f32;
                Some(SpriteTex {
                    handle,
                    uv: egui::Rect::from_min_max(egui::Pos2::ZERO, egui::pos2(1.0, frame_frac)),
                })
            }
            _ => None,
        };
        self.textures.insert(id, entry.clone());
        self.order.push_back(id);
        self.evict();
        entry
    }

    /// Move a used id to the back of the eviction queue.
    fn promote(&mut self, id: i32) {
        if let Some(pos) = self.order.iter().position(|&x| x == id) {
            self.order.remove(pos);
        }
        self.order.push_back(id);
    }

    fn evict(&mut self) {
        while self.order.len() > self.cap {
            if let Some(old) = self.order.pop_front() {
                self.textures.remove(&old);
            }
        }
    }
}

pub struct App {
    db: &'static terra_assets::ItemDb,
    settings: UiSettings,

    player: Option<terra_core::PlayerFile>,
    path: Option<PathBuf>,
    dirty: bool,
    status: String,
    status_is_error: bool,

    tab: Tab,
    selected_loadout: u8,
    selected: Option<SlotRef>,
    /// Which character `selected` points into.
    selected_side: Side,

    /// In-progress drag-and-drop, if any.
    drag: Option<Drag>,

    search: String,
    cat: u32,
    catalog: Catalog,

    open_picker: bool,
    /// When set, the picker loads a stash character instead of replacing the hero.
    picker_for_stash: bool,
    picker_filter: String,
    manual_path: String,
    players: Vec<PlayerEntry>,

    /// Optional second character for transferring items between saves.
    stash: Option<Stash>,

    show_settings: bool,
    hovered_item: Option<i32>,
    sprites: SpriteCache,
}

impl App {
    pub fn new(cc: &eframe::CreationContext<'_>) -> Self {
        let settings = UiSettings::load().clamped();
        apply_theme(&cc.egui_ctx, settings.zoom);

        let mut app = Self {
            db: terra_assets::ItemDb::embedded(),
            settings,
            player: None,
            path: None,
            dirty: false,
            status: "Open a character to begin.".to_owned(),
            status_is_error: false,
            tab: Tab::Inventory,
            selected_loadout: 0,
            selected: None,
            selected_side: Side::Primary,
            drag: None,
            search: String::new(),
            cat: 0,
            catalog: Catalog::default(),
            open_picker: true,
            picker_for_stash: false,
            picker_filter: String::new(),
            manual_path: String::new(),
            players: Vec::new(),
            stash: None,
            prefix_filter: String::new(),
            journey_filter: String::new(),
            show_settings: false,
            hovered_item: None,
            sprites: SpriteCache::new(2500),
        };
        app.rebuild_catalog();
        app.rescan();

        if let Some(arg) = std::env::args().nth(1) {
            app.open(PathBuf::from(arg));
            // Opening straight into a character should not leave the picker on top.
            app.open_picker = app.player.is_none();
        }
        // Screenshot/manual-check hook: open a second character immediately so
        // the split stash view can be reached without a mouse.
        if let Some(stash) = std::env::var_os("TF_STASH") {
            app.open_stash(PathBuf::from(stash));
        }
        // Handy for screenshots and manual checking without a mouse.
        if let Ok(tab) = std::env::var("TF_TAB") {
            app.tab = match tab.as_str() {
                "banks" => Tab::Banks,
                "buffs" => Tab::Buffs,
                "journey" => Tab::Journey,
                "raw" => Tab::Raw,
                _ => Tab::Inventory,
            };
        }
        app
    }

    // ------------------------------------------------------------ file actions

    fn rescan(&mut self) {
        self.players = terra_core::discover_players()
            .into_iter()
            .map(PlayerEntry::probe)
            .collect();
    }

    fn open(&mut self, path: PathBuf) {
        match terra_core::load(&path) {
            Ok(p) => {
                self.set_status(
                    format!(
                        "Loaded {} (v{}, {})",
                        path.file_name().unwrap_or_default().to_string_lossy(),
                        p.version,
                        p.format_name()
                    ),
                    false,
                );
                self.path = Some(path);
                self.player = Some(p);
                self.dirty = false;
                self.selected_side = Side::Primary;
                self.selected = Some(SlotRef {
                    c: Ct::Bag(Bag::Inv),
                    i: 0,
                });
                self.tab = Tab::Inventory;
            }
            Err(e) => self.set_status(format!("Could not open: {e}"), true),
        }
    }

    fn save(&mut self) {
        let Some(player) = &self.player else { return };
        let Some(path) = self.path.clone() else {
            self.set_status("No file path to save to.", true);
            return;
        };
        match terra_core::save_with_backup(&path, player) {
            Ok(bak) => {
                let mut msg = format!("Saved {}", path.display());
                if bak.as_os_str().is_empty() {
                    msg.push_str(" (new file, nothing to back up)");
                } else {
                    msg.push_str(&format!(
                        " (backup: {})",
                        bak.file_name().unwrap_or_default().to_string_lossy()
                    ));
                }
                self.set_status(msg, false);
                self.dirty = false;
                self.rescan();
            }
            Err(e) => self.set_status(format!("Save failed: {e}"), true),
        }
    }

    /// Load the optional second character. It is deliberately not discovered
    /// automatically: silently opening somebody else's character as a stash
    /// would be a surprising thing for a file editor to do.
    fn open_stash(&mut self, path: PathBuf) {
        match terra_core::load(&path) {
            Ok(player) => {
                let name = player.name.clone();
                self.stash = Some(Stash {
                    path,
                    player,
                    dirty: false,
                });
                self.set_status(format!("Stash character: {name}"), false);
                self.tab = Tab::Inventory;
            }
            Err(e) => self.set_status(format!("Could not open stash: {e}"), true),
        }
    }

    fn save_stash(&mut self) {
        let Some(mut stash) = self.stash.take() else {
            return;
        };
        match terra_core::save_with_backup(&stash.path, &stash.player) {
            Ok(_) => {
                stash.dirty = false;
                let name = stash.player.name.clone();
                self.stash = Some(stash);
                self.set_status(format!("Stash saved: {name}"), false);
            }
            Err(e) => {
                self.stash = Some(stash);
                self.set_status(format!("Stash save failed: {e}"), true);
            }
        }
    }

    fn set_status(&mut self, msg: impl Into<String>, is_error: bool) {
        self.status = msg.into();
        self.status_is_error = is_error;
    }

    // -------------------------------------------------------------- catalogue

    fn rebuild_catalog(&mut self) {
        self.catalog = Catalog::build(self.db, &self.search, self.cat);
    }

    /// Drop `drag` onto `to`: dragging from a slot swaps the two, dragging from
    /// the browser copies. All the actual byte-level rules live in `operations`.
    ///
    /// When the drag started on one character and ends on the other, the two
    /// models are handed to `operations::transfer_item` together.
    fn drop_on(&mut self, side: Side, to: SlotRef, drag: Drag) {
        let db = self.db;
        match (drag.side, side) {
            (Side::Primary, Side::Primary) => {
                if let Some(p) = self.player.as_mut() {
                    operations::drop_item(db, p, to, drag.from, drag.item);
                    self.dirty = true;
                }
            }
            (Side::Stash, Side::Stash) => {
                if let Some(s) = self.stash.as_mut() {
                    operations::drop_item(db, &mut s.player, to, drag.from, drag.item);
                    s.dirty = true;
                }
            }
            (Side::Primary, Side::Stash) => {
                if let (Some(p), Some(s)) = (self.player.as_mut(), self.stash.as_mut()) {
                    operations::transfer_item(db, p, &mut s.player, to, drag.from, drag.item);
                    s.dirty = true;
                }
            }
            (Side::Stash, Side::Primary) => {
                if let (Some(s), Some(p)) = (self.stash.as_mut(), self.player.as_mut()) {
                    operations::transfer_item(db, &mut s.player, p, to, drag.from, drag.item);
                    self.dirty = true;
                }
            }
        }
        self.selected = Some(to);
        self.selected_side = side;
    }

    /// Put an item into a slot without a source slot (browser click / duplicate).
    fn place(&mut self, to: SlotRef, item: Slot) {
        self.drop_on(
            self.selected_side,
            to,
            Drag {
                side: self.selected_side,
                from: None,
                item,
            },
        );
    }

    fn clear_slot(&mut self, side: Side, r: SlotRef) {
        if let Some(p) = self.player_mut(side) {
            operations::clear(p, r);
            self.mark_dirty(side);
        }
    }

    fn player_of(&self, side: Side) -> Option<&terra_core::PlayerFile> {
        match side {
            Side::Primary => self.player.as_ref(),
            Side::Stash => self.stash.as_ref().map(|s| &s.player),
        }
    }

    fn player_mut(&mut self, side: Side) -> Option<&mut terra_core::PlayerFile> {
        match side {
            Side::Primary => self.player.as_mut(),
            Side::Stash => self.stash.as_mut().map(|s| &mut s.player),
        }
    }

    fn is_dirty(&self, side: Side) -> bool {
        match side {
            Side::Primary => self.dirty,
            Side::Stash => self.stash.as_ref().map(|s| s.dirty).unwrap_or(false),
        }
    }

    fn mark_dirty(&mut self, side: Side) {
        match side {
            Side::Primary => self.dirty = true,
            Side::Stash => {
                if let Some(s) = self.stash.as_mut() {
                    s.dirty = true;
                }
            }
        }
    }

    fn describe(&self, slot: &Slot, ct: Option<Ct>) -> String {
        if slot.is_empty() {
            return "empty".into();
        }
        let mut s = format!("#{} {}", slot.net_id, self.db.display_name(slot.net_id));
        if let Some(p) = self.db.prefix_name(slot.prefix) {
            s.push_str(&format!(" · {p}"));
        }
        // Only containers that actually store a stack get a ×N suffix; a piece
        // of armour dragged from the bank into an equipment slot must not claim
        // to be a stack of twelve.
        if slot.stack > 1 && ct.map(is_multi).unwrap_or(true) {
            s.push_str(&format!(" ×{}", slot.stack));
        }
        s
    }
}

// -------------------------------------------------------------------- theme

/// Dark palette plus the user's zoom factor. Zoom is applied through egui's own
/// zoom factor so every widget, glyph and padding scales together.
fn apply_theme(ctx: &egui::Context, zoom: f32) {
    let mut visuals = egui::Visuals::dark();
    visuals.panel_fill = Color32::from_rgb(24, 26, 32);
    visuals.window_fill = Color32::from_rgb(28, 30, 36);
    ctx.set_visuals(visuals);
    ctx.all_styles_mut(|style| {
        use egui::{FontFamily::Proportional, FontId, TextStyle};
        style.spacing.item_spacing = Vec2::new(6.0, 6.0);
        style.spacing.button_padding = Vec2::new(8.0, 4.0);
        // Slightly larger than egui's defaults: the item grid is dense and a
        // 10 px "small" style is unreadable at arm's length.
        style.text_styles = [
            (TextStyle::Heading, FontId::new(21.0, Proportional)),
            (TextStyle::Body, FontId::new(15.0, Proportional)),
            (TextStyle::Button, FontId::new(15.0, Proportional)),
            (TextStyle::Small, FontId::new(12.5, Proportional)),
            (
                TextStyle::Monospace,
                FontId::new(13.0, egui::FontFamily::Monospace),
            ),
        ]
        .into();
    });
    ctx.set_zoom_factor(zoom);
}

// ---------------------------------------------------------------------- app

impl eframe::App for App {
    fn ui(&mut self, ui: &mut egui::Ui, _frame: &mut eframe::Frame) {
        let ctx = ui.ctx().clone();
        let ctrl = ctx.input(|i| i.modifiers.ctrl || i.modifiers.command);

        if ctrl && ctx.input(|i| i.key_pressed(egui::Key::S)) {
            self.save();
        }
        // Ctrl+O re-scans before opening: the character may have been created
        // since the last scan, and that is exactly when someone reaches for it.
        if ctrl && ctx.input(|i| i.key_pressed(egui::Key::O)) {
            self.rescan();
            self.picker_for_stash = false;
            self.open_picker = true;
        }
        // Ctrl+F focuses the item search, but only when no text box already has
        // focus — otherwise Ctrl+F in the path field would steal the caret.
        if ctrl
            && ctx.input(|i| i.key_pressed(egui::Key::F))
            && ctx.memory(|m| m.focused()).is_none()
        {
            ctx.memory_mut(|m| m.request_focus(egui::Id::unique("item-search")));
        }
        // Escape and right-click cancel a drag, matching the footer's promise.
        // This happens before the slots are drawn so the release that ends a
        // real drop is not mistaken for a cancel (that is why the generic
        // "released anywhere" cleanup runs at the *end* of the frame).
        if self.drag.is_some()
            && (ctx.input(|i| i.key_pressed(egui::Key::Escape))
                || ctx.input(|i| i.pointer.secondary_clicked()))
        {
            self.drag = None;
        }

        self.top_bar(ui);
        self.status_bar(ui);
        self.side_left(ui);
        self.side_right(ui);
        self.central(ui);
        self.picker_window(&ctx);
        self.settings_window(&ctx);
        self.drag_ghost(&ctx);

        // A drag that ends over nothing is simply cancelled. Deliberately last:
        // slots get first refusal on the release, then whatever is left over is
        // a drop on empty space.
        if self.drag.is_some() && ctx.input(|i| i.pointer.any_released()) {
            self.drag = None;
        }
    }
}

                        p.mana_now = p.mana_now.clamp(0, p.mana_max.max(0));
                    }

                    ui.add_space(8.0);
                    ui.label(RichText::new("Permanent upgrades").strong());
                    changed |= ui
                        .checkbox(&mut p.extra_accessory, "Demon Heart (+1 accessory slot)")
                        .changed();
                    changed |= ui
                        .checkbox(&mut p.ate_artisan_bread, "Artisan Loaf")
                        .changed();
                    changed |= ui
                        .checkbox(&mut p.unlocked_biome_torches, "Unlocked biome torches")
                        .changed();
                    changed |= ui
                        .checkbox(&mut p.using_biome_torches, "Using biome torches")
                        .changed();
                    changed |= ui
                        .checkbox(&mut p.finished_dd2_event, "Old One's Army completed")
                        .changed();
                    // The six 1.4.4 permanent boosters, in the order the file
                    // stores them (see `PlayerFile::extra_using_flags`). The
                    // first one's internal name is `AegisCrystal` but the item
                    // the player actually consumes is the Vital Crystal.
                    if p.version >= terra_core::plr::VER_1_4_4_0 {
                        for (flag, name) in p.extra_using_flags.iter_mut().zip([
                            "Vital Crystal (life regen)",
                            "Aegis Fruit (defence)",
                            "Arcane Crystal (mana regen)",
                            "Galaxy Pearl (luck)",
                            "Gummy Worm (fishing)",
                            "Ambrosia (mining speed)",
                        ]) {
                            changed |= ui.checkbox(flag, name).changed();
                        }
                    }

                    ui.add_space(8.0);
                    ui.label(RichText::new("Colours").strong());
                    for (name, c) in [
                        ("hair", &mut p.hair_color),
                        ("skin", &mut p.skin_color),
                        ("eyes", &mut p.eye_color),
                        ("shirt", &mut p.shirt_color),
                        ("undershirt", &mut p.under_color),
                        ("pants", &mut p.pants_color),
                        ("shoes", &mut p.shoes_color),
                    ] {
                        ui.horizontal(|ui| {
                            let mut rgb = [c.r, c.g, c.b];
                            if ui.color_edit_button_srgb(&mut rgb).changed() {
                                c.r = rgb[0];
                                c.g = rgb[1];
                                c.b = rgb[2];
                                changed = true;
                            }
                            ui.label(name);
                        });
                    }

                    ui.add_space(8.0);
                    ui.label(RichText::new("Journey").strong());
                    ui.label(
                        RichText::new(format!("{} items researched", p.research.len())).weak(),
                    );
                    ui.label(
                        RichText::new(format!(
                            "{} creative powers active",
                            p.creative_powers.len()
                        ))
                        .weak(),
                    );

                    if changed {
                        self.dirty = true;
                    }
                });
            });

    /// Editable view of the currently selected slot: prefix, stack, favourite.
    ///
    /// This exists because a slot cell can only show a picture and a number.
    /// Prefixes have 84 legal values, and choosing one from a grid would be
    /// absurd; the inspector is the honest place for it.
    fn inspector(&mut self, ui: &mut egui::Ui) {
        let Some(r) = self.selected else { return };
        let side = self.selected_side;
        let Some(slot) = self
            .player_of(side)
            .and_then(|p| container(p, r.c).get(r.i).copied())
        else {
            return;
        };
        if slot.is_empty() {
            return;
        }
        let db = self.db;
        ui.separator();
        ui.label(RichText::new("Selected slot").strong());
        ui.label(
            RichText::new(format!(
                "{}  [#{} · {} #{}]",
                db.display_name(slot.net_id),
                slot.net_id,
                container_label(r.c),
                r.i
            ))
            .weak()
            .small(),
        );

        // Prefix: a filtered combo box. The filter field lives in `App` because
        // egui keeps no widget state of its own between frames.
        let current = if slot.prefix == 0 {
            "None (0)".to_string()
        } else {
            match db.prefix_name(slot.prefix) {
                Some(name) => format!("#{} · {name}", slot.prefix),
                None => format!("#{} · unknown", slot.prefix),
            }
        };
        ui.horizontal(|ui| {
            ui.label("Prefix");
            egui::ComboBox::from_id_salt("prefix-combo")
                .selected_text(current)
                .width(190.0)
                .show_ui(ui, |ui| {
                    ui.add(
                        egui::TextEdit::singleline(&mut self.prefix_filter)
                            .hint_text("filter prefixes…")
                            .desired_width(180.0),
                    );
                    let filter = self.prefix_filter.to_lowercase();
                    let mut chosen: Option<u8> = None;
                    if ui.selectable_label(slot.prefix == 0, "None (0)").clicked() {
                        chosen = Some(0);
                    }
                    for prefix in &self.db.prefixes {
                        if !filter.is_empty() && !prefix.name.to_lowercase().contains(&filter) {
                            continue;
                        }
                        if ui
                            .selectable_label(
                                slot.prefix == prefix.id,
                                format!("#{} · {}", prefix.id, prefix.name),
                            )
                            .clicked()
                        {
                            chosen = Some(prefix.id);
                        }
                    }
                    if let Some(prefix) = chosen {
                        if let Some(p) = self.player_mut(side) {
                            if operations::set_prefix(p, r, prefix) {
                                self.mark_dirty(side);
                            }
                        }
                    }
                });
        });

        if is_multi(r.c) {
            ui.horizontal(|ui| {
                ui.label("Stack");
                let max = db.max_stack(slot.net_id).max(1);
                let mut stack = slot.stack;
                let response = ui.add(
                    egui::DragValue::new(&mut stack)
                        .speed(1)
                        .range(1..=max)
                        .suffix(format!(" / {max}")),
                );
                if response.changed() {
                    if let Some(p) = self.player_mut(side) {
                        if operations::set_stack(db, p, r, stack) {
                            self.mark_dirty(side);
                        }
                    }
                }
            });
        }

        ui.horizontal(|ui| {
            let mut favourite = slot.favorited;
            if ui
                .checkbox(&mut favourite, "Favourite")
                .on_hover_text("The star keeps the item in place when you quick-stack in game")
                .changed()
            {
                if let Some(p) = self.player_mut(side) {
                    if operations::toggle_favourite(p, r) {
                        self.mark_dirty(side);
                    }
                }
            }
            if ui.button("Clear slot").clicked() {
                self.clear_slot(side, r);
            }
        });
    }

    /// A section heading inside the item list.
    fn header_row(&self, ui: &mut egui::Ui, text: &str) {
        let (rect, _) =
            ui.allocate_exact_size(Vec2::new(ui.available_width(), 24.0), Sense::hover());
        ui.painter()
            .rect_filled(rect, 0.0, Color32::from_rgb(36, 40, 48));
        ui.painter().text(
            rect.min + Vec2::new(6.0, 12.0),
            egui::Align2::LEFT_CENTER,
            text.to_uppercase(),
            egui::FontId::proportional(11.0),
            Color32::from_rgb(150, 165, 190),
        );
    }

    /// One item row: drag source and click-to-place target.
    fn item_row(&mut self, ui: &mut egui::Ui, id: i32) {
        let Some(item) = self.db.by_id(id) else {
            return;
        };
        let (rect, resp) = ui.allocate_exact_size(
            Vec2::new(ui.available_width(), 24.0),
            Sense::click_and_drag(),
        );
        let hovered = resp.hovered();
        if hovered {
            ui.painter()
                .rect_filled(rect, 2.0, Color32::from_rgb(42, 46, 56));
        }
        let icon = egui::Rect::from_min_size(rect.min + Vec2::new(2.0, 1.0), Vec2::splat(22.0));
        ui.painter()
            .rect_filled(icon, 2.0, Color32::from_rgb(34, 37, 46));
        let sprite = if self.settings.sprites {
            self.sprites.get(ui.ctx(), item.id)
        } else {
            None
        };
        match sprite {
            Some(texture) => {
                // Use one animation frame, not the whole strip, so a 4-frame
                // soul is not shrunk to a quarter of its size.
                let native = texture.frame_size();
                let max_side = native.x.max(native.y);
                let fit = (icon.width() - 2.0) / max_side;
                let scale = if fit >= 2.0 { 2.0 } else { fit.min(1.0) };
                let target = egui::Rect::from_center_size(icon.center(), native * scale);
                ui.painter()
                    .image(texture.handle.id(), target, texture.uv, Color32::WHITE);
            }
            None => {
                ui.painter().rect_filled(
                    egui::Rect::from_min_size(icon.min, Vec2::new(2.0, icon.height())),
                    1.0,
                    rarity_color(item.rarity),
                );
                let initials: String = item
                    .name
                    .split_whitespace()
                    .take(2)
                    .map(|w| w.chars().next().unwrap_or('?'))
                    .collect();
                ui.painter().text(
                    icon.center(),
                    egui::Align2::CENTER_CENTER,
                    initials,
                    egui::FontId::proportional(9.0),
                    rarity_color(item.rarity),
                );
            }
        }
        ui.painter().text(
            rect.min + Vec2::new(26.0, 12.0),
            egui::Align2::LEFT_CENTER,
            &item.name,
            egui::FontId::proportional(13.0),
            Color32::from_gray(220),
        );
        ui.painter().text(
            rect.max - Vec2::new(4.0, 12.0),
            egui::Align2::RIGHT_CENTER,
            format!("#{}", item.id),
            egui::FontId::monospace(10.0),
            Color32::from_gray(110),
        );

        if hovered {
            self.hovered_item = Some(id);
        }

        if resp.drag_started() {
            let item_slot = Slot::new(id, self.db.max_stack(id), 0);
            self.drag = Some(Drag {
                side: self.selected_side,
                from: None,
                item: item_slot,
            });
        }

        if resp.clicked() {
            let item_slot = Slot::new(id, self.db.max_stack(id), 0);
            match self.selected {
                Some(target) => self.place(target, item_slot),
                None => {
                    self.set_status(
                        format!(
                            "Holding {}. Click a slot to place it.",
                            self.db.display_name(id)
                        ),
                        false,
                    );
                    self.drag = Some(Drag {
                        side: self.selected_side,
                        from: None,
                        item: item_slot,
                    });
                }
            }
        }
    }

    fn browser_footer(&mut self, ui: &mut egui::Ui) {
        if let Some(id) = self.hovered_item {
            if let Some(item) = self.db.by_id(id) {
                ui.label(RichText::new(&item.name).strong());
                let mut bits = Vec::new();
                if item.damage >= 0 {
                    bits.push(format!("{} damage", item.damage));
                }
                if item.defense > 0 {
                    bits.push(format!("{} defense", item.defense));
                }
                bits.push(format!("max stack {}", item.max_stack));
                if item.estimated {
                    bits.push("stats estimated (newer than the snapshot)".into());
                }
                ui.label(RichText::new(bits.join(" · ")).weak().small());
                return;
            }
        }
        if let Some(d) = &self.drag {
            ui.label(
                RichText::new(format!("Holding: {}", self.describe(&d.item, None)))
                    .color(Color32::from_rgb(205, 195, 130)),
            );
            ui.label(
                RichText::new("Drop it on a slot, or right-click to cancel.")
                    .weak()
                    .small(),
            );
        } else {
            ui.label(
                RichText::new(
                    "Drag an item onto a slot, or click a slot first and then click an item.",
                )
                .weak()
                .small(),
            );
        }
    }

    fn central(&mut self, ui0: &mut egui::Ui) {
        egui::CentralPanel::default().show(ui0, |ui| {
            if self.player.is_none() {
                ui.add_space(16.0);
                ui.label(RichText::new("No character open — use Open… in the top bar.").weak());
                return;
            }

            ui.horizontal_wrapped(|ui| {
                for (t, name) in [
                    (Tab::Inventory, "Inventory & equipment"),
                    (Tab::Banks, "Banks"),
                    (Tab::Buffs, "Buffs"),
                    (Tab::Journey, "Journey"),
                    (Tab::Raw, "File header"),
                ] {
                    if ui.selectable_label(self.tab == t, name).clicked() {
                        self.tab = t;
                    }
                }
            });
            ui.separator();

            // Journey owns its scroll area: the list is virtualised over 5,000+
            // rows and must fill the remaining height, which a nested ScrollArea
            // inside the generic "main" one cannot do (the outer one gives its
            // children unbounded height).
            if self.tab == Tab::Journey {
                self.tab_journey(ui);
            } else {
                egui::ScrollArea::vertical()
                    .id_salt("main")
                    .show(ui, |ui| match self.tab {
                        Tab::Inventory => self.tab_inventory(ui),
                        Tab::Banks => self.tab_banks(ui),
                        Tab::Buffs => self.tab_buffs(ui),
                        Tab::Journey => unreachable!("handled above"),
                        Tab::Raw => self.tab_raw(ui),
                    });
            }
        });
    }

    fn tab_inventory(&mut self, ui: &mut egui::Ui) {
        if self.stash.is_some() {
            // Two characters, side by side: the whole point is to drag across.
            let width = ((ui.available_width() - 24.0) / 2.0).max(180.0);
            let height = ui.available_height();
            ui.horizontal_top(|ui| {
                ui.allocate_ui_with_layout(
                    Vec2::new(width, height),
                    egui::Layout::top_down(egui::Align::Min),
                    |ui| {
                        self.pane_heading(ui, Side::Primary);
                        self.pane_primary(ui);
                    },
                );
                ui.separator();
                ui.allocate_ui_with_layout(
                    Vec2::new(width, height),
                    egui::Layout::top_down(egui::Align::Min),
                    |ui| {
                        self.pane_heading(ui, Side::Stash);
                        self.pane_stash(ui);
                    },
                );
            });
            return;
        }
        self.pane_primary(ui);
    }

    fn pane_heading(&self, ui: &mut egui::Ui, side: Side) {
        let name = self
            .player_of(side)
            .map(|p| p.name.clone())
            .unwrap_or_else(|| "—".into());
        let star = if self.is_dirty(side) { " *" } else { "" };
        // Both characters can share a name (Terraria allows it), and a narrow
        // pane truncates whatever is longest. Label the stash pane with its role
        // rather than a name that may not fit.
        let text = if side == Side::Stash {
            format!("Stash{star}")
        } else {
            format!("{name}{star}")
        };
        ui.add(egui::Label::new(RichText::new(text).heading()).truncate());
        ui.separator();
    }

    fn pane_primary(&mut self, ui: &mut egui::Ui) {
        ui.horizontal(|ui| {
            ui.label("Loadout");
            for (i, label) in ["1 (active)", "2", "3", "4"].iter().enumerate() {
                if ui
                    .selectable_label(self.selected_loadout == i as u8, *label)
                    .clicked()
                {
                    self.selected_loadout = i as u8;
                }
            }
        });

        let lo = self.selected_loadout;
        let (items, social, dyes) = if lo == 0 {
            (
                Ct::ActiveL(Group::Items),
                Ct::ActiveL(Group::Social),
                Ct::ActiveL(Group::Dyes),
            )
        } else {
            (
                Ct::StoredL(lo - 1, Group::Items),
                Ct::StoredL(lo - 1, Group::Social),
                Ct::StoredL(lo - 1, Group::Dyes),
            )
        };
        self.section(ui, "Armor & accessories", items);
        self.section(ui, "Vanity", social);
        self.section(ui, "Dyes", dyes);
        self.section(ui, "Main inventory", Ct::Bag(Bag::Inv));
        ui.horizontal(|ui| {
            ui.vertical(|ui| self.section(ui, "Coins", Ct::Bag(Bag::Coins)));
            ui.vertical(|ui| self.section(ui, "Ammo", Ct::Bag(Bag::Ammo)));
        });
        self.section(
            ui,
            "Pets · carts · mounts · hooks",
            Ct::Bag(Bag::EquipItems),
        );
        self.section(ui, "Misc dyes", Ct::Bag(Bag::EquipDyes));
    }

    fn tab_buffs(&mut self, ui: &mut egui::Ui) {
        ui.label(RichText::new("Buffs (id / duration in ticks). 44 slots on disk.").weak());
        let mut clear: Option<usize> = None;
        let count = self.player.as_ref().map(|p| p.buffs.len()).unwrap_or(0);
        for i in 0..count {
            let Some(p) = &mut self.player else { break };
            let b = &mut p.buffs[i];
            ui.horizontal(|ui| {
                ui.label(RichText::new(format!("#{i:02}")).weak());
                let name = self
                    .db
                    .buffs
                    .iter()
                    .find(|x| x.id == b.id)
                    .map(|x| x.name.clone())
                    .unwrap_or_else(|| {
                        if b.id == 0 {
                            "—".into()
                        } else {
                            format!("buff {}", b.id)
                        }
                    });
                ui.add_sized(
                    [150.0, 18.0],
                    egui::Label::new(RichText::new(name).weak()).truncate(),
                );
                if ui
                    .add(egui::DragValue::new(&mut b.id).range(0..=400))
                    .changed()
                {
                    self.dirty = true;
                }
                if ui
                    .add(
                        egui::DragValue::new(&mut b.time)
                            .speed(60)
                            .range(0..=1_000_000),
                    )
                    .changed()
                {
                    self.dirty = true;
                }
                if ui.small_button("clear").clicked() {
                    clear = Some(i);
                }
            });
        }
        if let (Some(i), Some(p)) = (clear, &mut self.player) {
            p.buffs[i] = terra_core::plr::Buff::default();
            self.dirty = true;
        }
    }

    fn tab_journey(&mut self, ui: &mut egui::Ui) {
        let Some(p) = &self.player else { return };
        let researched = p.research.len();
        let with_goal = self
            .db
            .items
            .iter()
            .filter(|i| !i.pid.is_empty() && i.research_goal > 0)
            .count();
        ui.horizontal_wrapped(|ui| {
            ui.label(format!(
                "{researched} entries researched · {with_goal} items have a research goal"
            ));
            if ui
                .button("Research all")
                .on_hover_text(
                    "Set every item with a known goal to fully researched.\n\
                     Counts already higher than the goal are left alone. Revert undoes it.",
                )
                .clicked()
            {
                if let Some(p) = &mut self.player {
                    let changed = operations::research_all(self.db, p);
                    self.dirty = true;
                    self.set_status(format!("Research all: {changed} entries updated"), false);
                }
            }
        });
        ui.horizontal(|ui| {
            ui.label("Filter");
            ui.add(
                egui::TextEdit::singleline(&mut self.journey_filter)
                    .hint_text("name or id")
                    .desired_width(220.0),
            );
        });

        // The catalogue is ~6,200 items; only the visible rows are drawn, so
        // rebuilding this id list each frame keeps the list responsive without
        // a parallel cache to invalidate.
        let filter = self.journey_filter.trim().to_lowercase();
        let ids: Vec<i32> = self
            .db
            .items
            .iter()
            .filter(|i| !i.pid.is_empty() && i.research_goal > 0)
            .filter(|i| {
                filter.is_empty()
                    || i.name.to_lowercase().contains(&filter)
                    || i.id.to_string() == filter
            })
            .map(|i| i.id)
            .collect();
        let total = ids.len();
        // Any edit, from the DragValue or the Complete button, is applied after
        // the list is drawn: the closure below only has immutable access to the
        // player, which keeps the borrow checker happy and the update atomic.
        let mut edit: Option<(String, i32)> = None;
        egui::ScrollArea::vertical()
            .id_salt("journey")
            // Fill the panel instead of shrinking to the widest row: a 300 px
            // list in a 1,200 px pane looks broken and wastes the row space.
            .auto_shrink([false, false])
            .show_rows(ui, 22.0, total, |ui, range| {
                for idx in range {
                    let Some(item) = self.db.by_id(ids[idx]) else {
                        continue;
                    };
                    let current = self
                        .player
                        .as_ref()
                        .and_then(|p| p.research.iter().find(|(k, _)| *k == item.pid))
                        .map(|(_, n)| *n)
                        .unwrap_or(0);
                    ui.horizontal(|ui| {
                        ui.add_sized([200.0, 18.0], egui::Label::new(&item.name).truncate());
                        ui.label(RichText::new(format!("#{}", item.id)).weak().small());

    /// Draw a titled block of slots for the primary character.

    /// Draw a titled block of slots for either character.
    fn section_side(&mut self, ui: &mut egui::Ui, side: Side, title: &str, ct: Ct) {
        let n = self
            .player_of(side)
            .map(|p| container(p, ct).len())
            .unwrap_or(0);
        if n == 0 {
            return;
        }
        ui.add_space(6.0);
        ui.label(RichText::new(title).strong());
        // The game lays inventory out 10 wide. Keeping that shape matters, so the
        // first choice is to shrink the cells to fit; only if they would get too
        // small to read do we wrap into fewer columns instead.
        let gap = 6.0;
        let avail = ui.available_width();
        let wanted_cols = 10usize.min(n);
        let preferred = self.settings.cell_size;
        let fit_for_ten = ((avail + gap) / wanted_cols as f32 - gap).floor();
        let (cell, per_row) = if fit_for_ten >= 24.0 {
            (preferred.min(fit_for_ten), wanted_cols)
        } else {
            let cols = ((avail + gap) / (preferred + gap)).floor();
            (preferred, (cols as usize).clamp(1, wanted_cols))
        };
        let mut i = 0;
        while i < n {
            ui.horizontal(|ui| {
                for _ in 0..per_row {
                    if i >= n {
                        break;
                    }
                    self.slot_side(ui, side, SlotRef { c: ct, i }, cell);
                    i += 1;
                }
            });
        }
    }

    /// One inventory cell: paints the item, handles select/drag/scroll/context menu.
    fn slot_side(&mut self, ui: &mut egui::Ui, side: Side, r: SlotRef, cell: f32) {
        let Some(p) = self.player_of(side) else {
            return;
        };
        let slot = *container(p, r.c).get(r.i).unwrap_or(&Slot::empty());
        let multi = is_multi(r.c);
        let (rect, resp) = ui.allocate_exact_size(Vec2::splat(cell), Sense::click_and_drag());
        let painter = ui.painter_at(rect);

        let selected = self.selected == Some(r) && self.selected_side == side;
        let border = if selected {
            Stroke::new(2.0, Color32::from_rgb(240, 200, 90))
        } else if resp.hovered() && self.drag.is_some() {
            Stroke::new(2.0, Color32::from_rgb(150, 200, 255))
        } else {
            Stroke::new(1.0, Color32::from_rgb(64, 70, 84))
        };
        painter.rect_filled(rect.shrink(1.0), 3.0, Color32::from_rgb(34, 37, 46));
        painter.rect_stroke(rect.shrink(1.0), 3.0, border, egui::StrokeKind::Inside);

        if !slot.is_empty() {
            let rarity = self.db.by_id(slot.net_id).map(|i| i.rarity).unwrap_or(0);
            let sprite = if self.settings.sprites {
                self.sprites.get(ui.ctx(), slot.net_id)
            } else {
                None
            };

            match sprite {
                Some(texture) => {
                    // Draw at native size: upscaling a 16 px coin to fill a 48 px
                    // slot is what makes sprite grids look wrong. Only oversized
                    // art is scaled down, keeping pixel alignment.
                    //
                    // `frame_size` is one animation frame, not the whole strip:
                    // a soul's texture is 22x88, and drawing that whole thing
                    // would shrink it to a quarter of its proper size.
                    let native = texture.frame_size();
                    let room = cell - 8.0;
                    let max_side = native.x.max(native.y);
                    // Large art shrinks to fit; tiny art (coins, blocks, torches)
                    // gets an integer 2x so it does not vanish, which keeps every
                    // pixel on the grid. Anything in between stays native size.
                    let fit = room / max_side;
                    let scale = if fit >= 2.0 { 2.0 } else { fit.min(1.0) };
                    let target = egui::Rect::from_center_size(rect.center(), native * scale);
                    painter.image(texture.handle.id(), target, texture.uv, Color32::WHITE);
                    // Rarity stays visible, but as a quiet 2 px strip instead of a
                    // background wash that would fight the artwork.
                    painter.rect_filled(
                        egui::Rect::from_min_max(
                            egui::pos2(rect.left() + 3.0, rect.bottom() - 5.0),
                            egui::pos2(rect.right() - 3.0, rect.bottom() - 3.0),
                        ),
                        1.0,
                        rarity_color(rarity),
                    );
                }
                None => {
                    // Fallback: rarity tile with initials, as before.
                    painter.rect_filled(
                        rect.shrink(4.0),
                        2.0,
                        rarity_color(rarity).linear_multiply(0.85),
                    );
                    let initials: String = self
                        .db
                        .display_name(slot.net_id)
                        .split_whitespace()
                        .take(2)
                        .map(|w| w.chars().next().unwrap_or('?'))
                        .collect();
                    painter.text(
                        rect.center(),
                        egui::Align2::CENTER_CENTER,
                        initials,
                        egui::FontId::proportional(cell * 0.30),
                        Color32::from_black_alpha(200),
                    );
                }
            }

            if slot.stack > 1 && multi {
                // Shadow first, then the number: stacks stay readable on bright art.
                let text = slot.stack.to_string();
                let pos = rect.max - Vec2::new(3.0, 2.0);
                let font = egui::FontId::proportional(cell * 0.24);
                painter.text(
                    pos + Vec2::new(1.0, 1.0),
                    egui::Align2::RIGHT_BOTTOM,
                    &text,
                    font.clone(),
                    Color32::from_black_alpha(220),
                );
                painter.text(pos, egui::Align2::RIGHT_BOTTOM, &text, font, Color32::WHITE);
            }
            if slot.favorited {
                painter.text(
                    rect.min + Vec2::new(3.0, 1.0),
                    egui::Align2::LEFT_TOP,
                    "★",
                    egui::FontId::proportional(cell * 0.22),
                    Color32::from_rgb(250, 220, 120),
                );
            }
        }

        if resp.hovered() {
            self.hovered_item = if slot.is_empty() {
                None
            } else {
                Some(slot.net_id)
            };
            let tip = format!(
                "{}  [{} #{}]",
                self.describe(&slot, Some(r.c)),
                container_label(r.c),
                r.i
            );
            resp.clone().on_hover_text(tip);
        }

        // Wheel over a slot edits the stack, like the game does with right-click.
        if resp.hovered() && multi && !slot.is_empty() {
            let scroll = ui.input(|i| i.smooth_scroll_delta.y);
            if scroll.abs() > 0.1 {
                let step = if ui.input(|i| i.modifiers.shift) {
                    100
                } else {
                    1
                };
                let delta = if scroll > 0.0 { step } else { -step };
                let db = self.db;
                let changed = match self.player_mut(side) {
                    Some(p) => operations::bump_stack(db, p, r, delta),
                    None => false,
                };
                if changed {
                    self.mark_dirty(side);
                }
            }
        }

        if resp.drag_started() && !slot.is_empty() {
            self.drag = Some(Drag {
                side,
                from: Some(r),
                item: slot,
            });
        }
        if resp.dragged() {
            // repaint the source as "in flight" so the user sees what moved
            painter.rect_stroke(
                rect.shrink(1.0),
                3.0,
                Stroke::new(1.0, Color32::from_rgb(120, 130, 150)),
                egui::StrokeKind::Inside,
            );
        }

        // Dropping: the slot under the cursor wins on release.
        if let Some(drag) = self.drag {
            if resp.hovered() && ui.input(|i| i.pointer.any_released()) {
                self.drop_on(side, r, drag);
                self.drag = None;
            }
        }

        if resp.clicked() {
            self.selected = Some(r);
            self.selected_side = side;
            if let Some(drag) = self.drag.take() {
                self.drop_on(side, r, drag);
            }
        }

        // Right-click: the explicit route, for people who prefer menus.
        let mut action: Option<MenuAction> = None;
        resp.context_menu(|ui| {
            ui.label(RichText::new(self.describe(&slot, Some(r.c))).strong());
            ui.separator();
            let has = !slot.is_empty();
            if ui
                .add_enabled(has, egui::Button::new("Pick up (drag)"))
                .clicked()
            {
                action = Some(MenuAction::Pick);
                ui.close();
            }
            if ui
                .add_enabled(has, egui::Button::new("Duplicate"))
                .clicked()
            {
                action = Some(MenuAction::Duplicate);
                ui.close();
            }
            if ui
                .add_enabled(has && multi, egui::Button::new("Max stack"))
                .clicked()
            {
                action = Some(MenuAction::MaxStack);
                ui.close();
            }
            if ui
                .add_enabled(has, egui::Button::new("Toggle favourite"))
                .clicked()
            {
                action = Some(MenuAction::Favourite);
                ui.close();
            }
            if ui
                .add_enabled(has, egui::Button::new("Clear slot"))
                .clicked()
            {
                action = Some(MenuAction::Clear);
                ui.close();
            }
        });

        match action {
            Some(MenuAction::Pick) => {
                self.drag = Some(Drag {
                    side,
                    from: Some(r),
                    item: slot,
                })
            }
            Some(MenuAction::Duplicate) => {
                self.drag = Some(Drag {
                    side,
                    from: None,
                    item: slot,
                })
            }
            Some(MenuAction::MaxStack) => {
                let db = self.db;
                let changed = match self.player_mut(side) {
                    Some(p) => operations::max_stack(db, p, r),
                    None => false,
                };
                if changed {
                    self.mark_dirty(side);
                }
            }
            Some(MenuAction::Favourite) => {
                let changed = match self.player_mut(side) {
                    Some(p) => operations::toggle_favourite(p, r),
                    None => false,
                };
                if changed {
                    self.mark_dirty(side);
                }
            }
            Some(MenuAction::Clear) => self.clear_slot(side, r),
            None => {}
        }

        if resp.middle_clicked() && !slot.is_empty() {
            self.drag = Some(Drag {
                side,
                from: None,
                item: slot,
            });
        }
    }

/// Friendly heading for a player's directory.
fn group_of(path: &std::path::Path) -> String {
    let dir = path
        .parent()
        .map(|p| p.display().to_string())
        .unwrap_or_default();
    if dir.contains("tModLoader") {
        return "tModLoader".to_string();
    }
    if dir.contains("userdata") {
        // .../steam/userdata/<account>/105600/remote/players
        let account = dir
            .split("userdata/")
            .nth(1)
            .and_then(|rest| rest.split('/').next())
            .unwrap_or("?");
        return format!("Steam Cloud · account {account}");
    }
    "Local".to_string()
}

/// Human duration for the header tab: `2 h 05 min`, `12 min 03 s`, `45 s`.
fn duration_label(seconds: u64) -> String {
    let h = seconds / 3600;
    let m = (seconds % 3600) / 60;
    let s = seconds % 60;
    if h > 0 {
        format!("{h} h {m:02} min")
    } else if m > 0 {
        format!("{m} min {s:02} s")
    } else {
        format!("{s} s")
    }
}

/// Team id → the colour the game shows, with the raw id kept for unknown values.
fn team_name(team: u8) -> String {
    match team {
        0 => "none".to_string(),
        1 => "red".to_string(),
        2 => "green".to_string(),
        3 => "blue".to_string(),
        4 => "yellow".to_string(),
        5 => "pink".to_string(),
        other => format!("unknown ({other})"),
    }
}

fn gender_name(gender: u8) -> String {
    match gender {
        0 => "male".to_string(),
        1 => "female".to_string(),
        other => format!("unknown ({other})"),
    }
}

fn difficulty_name(d: u8) -> &'static str {
    match d {
        0 => "Classic",
        1 => "Expert",
        2 => "Master",
        3 => "Creative (Journey)",
        _ => "Classic",
    }
}

//! Pure edit operations on a loaded player.
//!
//! These live outside the `App` struct on purpose: they take `&mut PlayerFile`,
//! touch no UI state, and can therefore be unit-tested without an egui context.
//! The UI is a thin skin over this module — when a drag ends, it calls
//! [`drop_item`]; when a stack is scrolled, it calls [`bump_stack`].

use terra_assets::ItemDb;
use terra_core::{PlayerFile, Slot};

use crate::containers::{container, container_mut, is_multi, Ct, SlotRef};

/// Force an item to fit its destination container.
///
/// Equipment slots have no stack field on disk, so anything dropped there
/// becomes a single item — otherwise the game would read a stack out of the
/// next field and the whole file would be garbage.
pub fn fit(db: &ItemDb, mut item: Slot, to: Ct) -> Slot {
    if item.net_id <= 0 {
        return Slot::empty();
    }
    if is_multi(to) {
        item.stack = item.stack.clamp(1, db.max_stack(item.net_id).max(1));
    } else {
        item.stack = 1;
    }
    item
}

/// Move or copy an item onto `to`.
///
/// * `from = Some(src)` — a move: whatever occupied `to` is placed into `src`,
///   i.e. the two slots swap. This matches Terraria's own inventory drag.
/// * `from = None` — a copy: the item is simply written into `to`.
pub fn drop_item(db: &ItemDb, p: &mut PlayerFile, to: SlotRef, from: Option<SlotRef>, item: Slot) {
    // A drag carrying nothing is not an instruction to erase the destination.
    if item.net_id <= 0 {
        return;
    }
    let incoming = fit(db, item, to.c);
    let displaced = container(p, to.c).get(to.i).copied().unwrap_or_default();
    if let Some(slot) = container_mut(p, to.c).get_mut(to.i) {
        *slot = incoming;
    }
    if let Some(src) = from {
        if src != to {
            let back = if displaced.net_id != 0 {
                fit(db, displaced, src.c)
            } else {
                Slot::empty()
            };
            if let Some(slot) = container_mut(p, src.c).get_mut(src.i) {
                *slot = back;
            }
        }
    }
}

/// Clear a slot.
pub fn clear(p: &mut PlayerFile, r: SlotRef) {
    if let Some(slot) = container_mut(p, r.c).get_mut(r.i) {
        *slot = Slot::empty();
    }
}

/// Add `delta` to a stack, clamped to `1..=max_stack`. No-op for containers that
/// do not store stacks.
pub fn bump_stack(db: &ItemDb, p: &mut PlayerFile, r: SlotRef, delta: i32) -> bool {
    if !is_multi(r.c) {
        return false;
    }
    let Some(current) = container(p, r.c).get(r.i).copied() else {
        return false;
    };
    if current.is_empty() {
        return false;
    }
    let max = db.max_stack(current.net_id).max(1);
    if let Some(slot) = container_mut(p, r.c).get_mut(r.i) {
        slot.stack = (slot.stack + delta).clamp(1, max);
        return true;
    }
    false
}

/// Set a stack to its maximum. Returns false if the slot is empty.
pub fn max_stack(db: &ItemDb, p: &mut PlayerFile, r: SlotRef) -> bool {
    let Some(current) = container(p, r.c).get(r.i).copied() else {
        return false;
    };
    if current.is_empty() || !is_multi(r.c) {
        return false;
    }
    let max = db.max_stack(current.net_id).max(1);
    if let Some(slot) = container_mut(p, r.c).get_mut(r.i) {
        slot.stack = max;
        return true;
    }
    false
}

/// Change an item's prefix (its random modifier: "Legendary", "Broken", …).
///
/// The prefix byte belongs to the item, not the slot, so an empty slot has
/// nothing to modify. `0` means "no prefix", which is a legal value — un-forging
/// an item is the same operation as reforging it.
pub fn set_prefix(p: &mut PlayerFile, r: SlotRef, prefix: u8) -> bool {
    match container_mut(p, r.c).get_mut(r.i) {
        Some(slot) if !slot.is_empty() => {
            slot.prefix = prefix;
            true
        }
        _ => false,
    }
}

/// Set a stack count explicitly, clamped to the item's maximum.
///
/// The inspector uses this rather than [`bump_stack`] because a typed value can
/// jump anywhere; equipment has no stack field to write, hence the `false`.
pub fn set_stack(db: &ItemDb, p: &mut PlayerFile, r: SlotRef, stack: i32) -> bool {
    if !is_multi(r.c) {
        return false;
    }
    let Some(current) = container(p, r.c).get(r.i).copied() else {
        return false;
    };
    if current.is_empty() {
        return false;
    }
    // A filled slot cannot hold zero items; emptying is `clear`'s job.
    if stack < 1 {
        return false;
    }
    let max = db.max_stack(current.net_id).max(1);
    if let Some(slot) = container_mut(p, r.c).get_mut(r.i) {
        slot.stack = stack.clamp(1, max);
        return true;
    }
    false
}

/// Move one item from `src` to `dst`, where the two may be different characters.
///
/// This is [`drop_item`] with the player split in two so the same code can move
/// gear between a character and the stash. Semantics are identical: with
/// `from = Some(src)` the destination's old item travels back to `src` (a swap);
/// with `from = None` the item is copied and the source slot is left alone.
pub fn transfer_item(
    db: &ItemDb,
    src: &mut PlayerFile,
    dst: &mut PlayerFile,
    to: SlotRef,
    from: Option<SlotRef>,
    item: Slot,
) {
    if item.net_id <= 0 {
        return;
    }
    let incoming = fit(db, item, to.c);
    let displaced = container(dst, to.c).get(to.i).copied().unwrap_or_default();
    if let Some(slot) = container_mut(dst, to.c).get_mut(to.i) {
        *slot = incoming;
    }
    if let Some(src_ref) = from {
        let back = if displaced.net_id != 0 {
            fit(db, displaced, src_ref.c)
        } else {
            Slot::empty()
        };
        if let Some(slot) = container_mut(src, src_ref.c).get_mut(src_ref.i) {
            *slot = back;
        }
    }
}

/// Journey-mode research bookkeeping.
///
/// Research lives in `PlayerFile::research` as `(persistent item id, count)`
/// pairs, independent of the item's net id, because the game identifies research
/// by its internal name (`Zenith`, `AegisCrystal`, …). Entries are only written
/// for items that have been researched at all, so adding one is normal — the
/// vector is the save file's own list, not a fixed-size table.
pub fn research_item(p: &mut PlayerFile, pid: &str, goal: i32) {
    if pid.is_empty() {
        return;
    }
    // Setting a count to zero means "not researched at all". Leaving a `pid -> 0`
    // entry behind would grow the save's research list with dead entries.
    if goal <= 0 {
        p.research.retain(|(k, _)| k != pid);
        return;
    }
    match p.research.iter_mut().find(|(k, _)| k == pid) {
        Some((_, count)) => *count = goal,
        None => p.research.push((pid.to_string(), goal)),
    }
}

/// Learn everything the catalogue knows a research goal for.
///
/// `preserve` is deliberate: a character that already researched past the goal
/// (possible with mods or a future balance change) must not be lowered. Returns
/// the number of entries actually changed, which the status bar reports.
pub fn research_all(db: &ItemDb, p: &mut PlayerFile) -> usize {
    let mut index: std::collections::HashMap<String, usize> = p
        .research
        .iter()
        .enumerate()
        .map(|(i, (k, _))| (k.clone(), i))
        .collect();
    let mut changed = 0usize;
    for item in &db.items {
        if item.pid.is_empty() || item.research_goal <= 0 {
            continue;
        }
        match index.get(&item.pid) {
            Some(&i) => {
                if p.research[i].1 < item.research_goal {
                    p.research[i].1 = item.research_goal;
                    changed += 1;
                }
            }
            None => {
                index.insert(item.pid.clone(), p.research.len());
                p.research.push((item.pid.clone(), item.research_goal));
                changed += 1;
            }
        }
    }
    changed
}

/// Flip the favourite star.
pub fn toggle_favourite(p: &mut PlayerFile, r: SlotRef) -> bool {
    match container_mut(p, r.c).get_mut(r.i) {
        Some(slot) if !slot.is_empty() => {
            slot.favorited = !slot.favorited;
            true
        }
        _ => false,
    }
}

//! User interface settings, persisted as JSON.
//!
//! Kept deliberately tiny and dependency-free: a handful of scalars written to
//! `~/.config/terra-forge/settings.json`. Loading never fails hard — a missing
//! or malformed file just yields defaults, because a settings file must never
//! be the reason someone cannot open their character.

use std::path::PathBuf;

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(default)]
pub struct UiSettings {
    /// Global zoom, applied through `egui::Context::set_zoom_factor`.
    /// 1.0 = the default size; useful range is roughly 0.8 .. 1.8.
    pub zoom: f32,
    /// Slot cell size in points, before zoom.
    pub cell_size: f32,
    /// Draw real item sprites decoded from the installed game.
    /// Turning this off restores the plain rarity tiles.
    pub sprites: bool,
}

impl Default for UiSettings {
    fn default() -> Self {
        Self {
            zoom: 1.25,
            cell_size: 48.0,
            sprites: true,
        }
    }
}

impl UiSettings {
    fn path() -> Option<PathBuf> {
        let dirs = std::env::var_os("XDG_CONFIG_HOME")
            .map(PathBuf::from)
            .or_else(|| std::env::var_os("HOME").map(|h| PathBuf::from(h).join(".config")))?;
        Some(dirs.join("terra-forge/settings.json"))
    }

    pub fn load() -> Self {
        let Some(path) = Self::path() else {
            return Self::default();
        };
        let Ok(text) = std::fs::read_to_string(&path) else {
            return Self::default();
        };
        serde_json::from_str(&text).unwrap_or_default()
    }

    pub fn save(&self) {
        let Some(path) = Self::path() else { return };
        if let Some(dir) = path.parent() {
            let _ = std::fs::create_dir_all(dir);
        }
        if let Ok(text) = serde_json::to_string_pretty(self) {
            let _ = std::fs::write(path, text);
        }
    }

    pub fn clamped(mut self) -> Self {
        self.zoom = self.zoom.clamp(0.7, 2.5);
        self.cell_size = self.cell_size.clamp(34.0, 72.0);
        self
    }
}

//! `tforge` — headless companion CLI for terra-forge.
//!
//! Used to inspect and verify player files without opening the GUI, and as the
//! reference harness for the round-trip guarantee: `tforge verify <file>` must
//! report "identical" for every file the GUI is willing to save.

use std::path::{Path, PathBuf};
use std::process::ExitCode;

use terra_core::{crypto, PlayerFile};

fn main() -> ExitCode {
    let args: Vec<String> = std::env::args().skip(1).collect();
    if args.is_empty() {
        usage();
        return ExitCode::from(2);
    }
    let cmd = args[0].as_str();
    let paths: Vec<PathBuf> = args[1..].iter().map(PathBuf::from).collect();

    match cmd {
        "info" => run(paths, cmd_info),
        "verify" => run(paths, cmd_verify),
        "inventory" => run(paths, cmd_inventory),
        "copy" => run(paths, cmd_copy),
        "selftest" => run(paths, cmd_selftest),
        "demo" => run(paths, cmd_demo),
        "-h" | "--help" | "help" => {
            usage();
            ExitCode::SUCCESS
        }
        other => {
            eprintln!("unknown command: {other}");
            usage();
            ExitCode::from(2)
        }
    }
}

fn usage() {
    eprintln!(
        "usage: tforge <command> <player.plr>...\n\
         \n\
         commands:\n\
         \x20 info       decode and summarise a player file\n\
         \x20 verify     prove decrypt->parse->serialise->encrypt is byte-identical\n\
         \x20 inventory  list non-empty inventory/equipment slots\n\
         \x20 copy       load and save to <file>.roundtrip via the GUI save path\n\
         \x20 selftest   apply a set of edits, save, reload and assert the edits stuck\n\
         \x20 demo       write a fresh demo character (safe sandbox, no real save touched)"
    );
}

fn run(paths: Vec<PathBuf>, f: fn(&Path) -> Result<(), String>) -> ExitCode {
    if paths.is_empty() {
        usage();
        return ExitCode::from(2);
    }
    let mut failed = 0;
    for p in &paths {
        println!("== {} ==", p.display());
        if let Err(e) = f(p) {
            println!("   ERROR: {e}");
            failed += 1;
        }
    }
    if failed > 0 {
        ExitCode::FAILURE
    } else {
        ExitCode::SUCCESS
    }
}

fn load(path: &Path) -> Result<PlayerFile, String> {
    let raw = std::fs::read(path).map_err(|e| format!("read: {e}"))?;
    let plain = crypto::decrypt(&raw).map_err(|e| format!("decrypt: {e}"))?;
    PlayerFile::parse(&plain).map_err(|e| format!("parse: {e}"))
}

fn cmd_verify(path: &Path) -> Result<(), String> {
    let raw = std::fs::read(path).map_err(|e| format!("read: {e}"))?;
    let plain = crypto::decrypt(&raw).map_err(|e| format!("decrypt: {e}"))?;
    let p = PlayerFile::parse(&plain).map_err(|e| format!("parse: {e}"))?;
    let out_plain = p.serialize();
    if out_plain != plain {
        let at = out_plain
            .iter()
            .zip(plain.iter())
            .position(|(a, b)| a != b)
            .unwrap_or(plain.len().min(out_plain.len()));
        return Err(format!(
            "PLAINTEXT MISMATCH at byte {at} (in {} bytes, out {} bytes, version {})",
            plain.len(),
            out_plain.len(),
            p.version
        ));
    }
    let out = crypto::encrypt(&out_plain).map_err(|e| format!("encrypt: {e}"))?;
    if out != raw {
        let at = out
            .iter()
            .zip(raw.iter())
            .position(|(a, b)| a != b)
            .unwrap_or(raw.len().min(out.len()));
        return Err(format!("CIPHERTEXT MISMATCH at byte {at}"));
    }
    println!(
        "   identical: {} bytes, version {}, trailing {} bytes",
        raw.len(),
        p.version,
        p.trailing.len()
    );
    Ok(())
}

fn cmd_inventory(path: &Path) -> Result<(), String> {
    let p = load(path)?;
    let db = terra_assets::ItemDb::embedded();
    fn collect<'a>(
        rows: &mut Vec<(String, usize, &'a terra_core::Slot)>,
        label: &str,
        slots: &'a [terra_core::Slot],
    ) {
        for (i, s) in slots.iter().enumerate() {
            if !s.is_empty() {
                rows.push((label.to_string(), i, s));
            }
        }
    }
    let mut rows: Vec<(String, usize, &terra_core::Slot)> = Vec::new();
    collect(&mut rows, "inv", &p.inventory);
    collect(&mut rows, "coins", &p.coins);
    collect(&mut rows, "ammo", &p.ammo);
    collect(&mut rows, "equip", &p.equipment_items);
    collect(&mut rows, "dye", &p.equipment_dyes);
    collect(&mut rows, "bank", &p.bank);
    collect(&mut rows, "safe", &p.safe);
    collect(&mut rows, "forge", &p.forge);
    collect(&mut rows, "void", &p.void_bag);
    collect(&mut rows, "armor", &p.active_loadout.items);
    collect(&mut rows, "vanity", &p.active_loadout.social);
    collect(&mut rows, "dyes", &p.active_loadout.dyes);
    for l in 0..3 {
        collect(
            &mut rows,
            &format!("loadout{}", l + 1),
            &p.stored_loadouts[l].items,
        );
    }
    for (label, i, s) in rows {
        let name = db
            .by_id(s.net_id)
            .map(|it| it.name.clone())
            .unwrap_or_else(|| format!("<item #{}>", s.net_id));
        let prefix = if s.prefix != 0 {
            format!(" [prefix {}]", s.prefix)
        } else {
            String::new()
        };
        println!(
            "   {label}[{i:2}] {:<32} x{:<6}{prefix}{}",
            name,
            s.stack,
            if s.favorited { " *fav" } else { "" }
        );
    }
    Ok(())
}

/// Exercise the exact save path the GUI uses (backup + temp file + read-back
/// verification) by writing a copy next to the source and verifying the result.
fn cmd_copy(path: &Path) -> Result<(), String> {
    let player = terra_core::load(path).map_err(|e| e.to_string())?;
    let mut out = path.to_path_buf();
    let stem = path
        .file_stem()
        .unwrap_or_default()
        .to_string_lossy()
        .to_string();
    out.set_file_name(format!("{stem}.roundtrip.plr"));
    let _ = std::fs::remove_file(terra_core::backup_path(&out));
    terra_core::save_with_backup(&out, &player).map_err(|e| format!("save: {e}"))?;
    let written = std::fs::read(&out).map_err(|e| e.to_string())?;
    let original = std::fs::read(path).map_err(|e| e.to_string())?;
    if written != original {
        return Err(format!(
            "saved copy differs from source ({} vs {} bytes)",
            written.len(),
            original.len()
        ));
    }
    println!(
        "   wrote {} ({} bytes, byte-identical to source)",
        out.display(),
        written.len()
    );
    Ok(())
}

/// Functional edit test: mutate the player in memory the same way the GUI does,
/// save through the backup path, reload from disk and assert every edit landed
/// while every untouched slot stayed identical.
fn cmd_selftest(path: &Path) -> Result<(), String> {
    let mut player = terra_core::load(path).map_err(|e| e.to_string())?;
    let before = player.clone();

    // pick a rich character or fall back to slot 0
    let idx = player
        .inventory
        .iter()
        .position(|s| !s.is_empty())
        .unwrap_or(0);
    player.inventory[idx] = terra_core::Slot {
        net_id: 4956,
        stack: 1,
        prefix: 82,
        favorited: true,
    };
    player.bank[3] = terra_core::Slot::new(2, 9999, 0);
    player.equipment_dyes[0] = terra_core::Slot::new(1050, 1, 0);
    player.health_max = 500;
    player.research.push(("Zenith".to_string(), 1));

    let out = {
        let mut o = path.to_path_buf();
        let stem = path
            .file_stem()
            .unwrap_or_default()
            .to_string_lossy()
            .to_string();
        o.set_file_name(format!("{stem}.edited.plr"));
        o
    };
    terra_core::save_with_backup(&out, &player).map_err(|e| format!("save: {e}"))?;

    let reloaded = terra_core::load(&out).map_err(|e| format!("reload: {e}"))?;

    let mut checks: Vec<(String, bool)> = Vec::new();
    checks.push((
        format!("inventory[{idx}] is Zenith/Mythical/favourite"),
        reloaded.inventory[idx]
            == terra_core::Slot {
                net_id: 4956,
                stack: 1,
                prefix: 82,
                favorited: true,
            },
    ));
    checks.push((
        "piggy bank slot 3 is 9999 dirt".to_string(),
        reloaded.bank[3].net_id == 2 && reloaded.bank[3].stack == 9999,
    ));
    checks.push((
        "dye slot holds item 1050".to_string(),
        reloaded.equipment_dyes[0].net_id == 1050,
    ));
    checks.push(("max life is 500".to_string(), reloaded.health_max == 500));
    checks.push((
        "research entry added".to_string(),
        reloaded
            .research
            .last()
            .map(|(p, c)| p == "Zenith" && *c == 1)
            .unwrap_or(false),
    ));

    // untouched regions must be byte-identical
    let mut untouched_ok = true;
    for i in reloaded
        .inventory
        .iter()
        .zip(before.inventory.iter())
        .enumerate()
    {
        let (n, (a, b)) = i;
        if n != idx && a != b {
            untouched_ok = false;
        }
    }
    checks.push((
        "all other inventory slots unchanged".to_string(),
        untouched_ok,
    ));
    checks.push((
        format!("trailing bytes preserved ({})", before.trailing.len()),
        reloaded.trailing == before.trailing,
    ));

    let mut failed = 0;
    for (label, ok) in checks {
        println!("   [{}] {label}", if ok { "ok" } else { "FAIL" });
        if !ok {
            failed += 1;
        }
    }
    println!("   wrote {}", out.display());
    if failed > 0 {
        return Err(format!("{failed} checks failed"));
    }
    Ok(())
}

# Learning guide: how terra-forge works

This is a guided tour of the code for someone who wants to understand *why* it is
built this way, not just what it does. Every section points at real functions you can
open and read.

---

## 1. The shape of the thing

```
Terraria saves a character as an encrypted blob.
We want to edit it without breaking it.
```

That sentence produces the whole architecture:

| crate | job | key idea |
|---|---|---|
| `terra-core` | bytes ⇄ `PlayerFile` | the only code that knows the file format |
| `terra-assets` | item names/ids/stats | a generated database, not hand-written tables |
| `terra-gui` | the editor | mutates a `PlayerFile` in memory; never touches bytes |

The GUI holds one `PlayerFile`. Everything it draws is a read of that struct, and every
edit is a write to it. Bytes only appear at two moments: `terra_core::load` and
`terra_core::save_with_backup`.

Why this split matters: the file format is the risky part. By keeping it in one crate
with no UI dependencies, it can be tested headlessly (and it is — `cargo test`, plus the
`tforge` CLI against real saves).

---

## 2. The encryption, in ten lines

`crates/terra-core/src/crypto.rs`

```rust
pub const KEY_BYTES: [u8; 16] = [
    0x68, 0x00, 0x33, 0x00, ... // "h3y_gUyZ" encoded as UTF-16LE
];
```

Terraria encrypts the whole payload with AES-128-CBC and — this is the interesting part —
uses the **same 16 bytes for the key and the IV**. That is a crypto smell in general, but
here it is a gift: CBC with a fixed IV is deterministic, so

```
decrypt(file) → parse → serialise → encrypt
```

must reproduce the original file **byte for byte**. That single property is what lets us
claim "this editor does not corrupt saves", and it is what `tforge verify` checks on real
files.

`encrypt`/`decrypt` also handle PKCS#7 padding. Note `decrypt` rejects input that is not a
multiple of 16 bytes; a `.plr` always is, so a failure there means the file is not a
player file at all.

---

## 3. Reading bytes the way .NET does

`crates/terra-core/src/cursor.rs`

Terraria is a C# game, so the file was written by `BinaryWriter`. Our `Reader` mirrors
exactly those primitives: little-endian `i32`, `u8`, `f32`, and — the one people get wrong
— strings:

```rust
// .NET BinaryWriter.Write(string):
//   7-bit LEB128 byte length, then UTF-8 bytes
pub fn string(&mut self) -> Result<String, IoError> {
    let mut len = 0u64;
    let mut shift = 0;
    loop {
        let b = self.u8()?;
        len |= ((b & 0x7F) as u64) << shift;
        if b & 0x80 == 0 { break; }
        shift += 7;
    }
    ...
}
```

A player name is at most a few dozen bytes, so one length byte; a long research id needs
two. The unit test `dotnet_string_prefixes` pins both cases, including the exact prefix
bytes for a 300-character string (`0xAC 0x02`).

`Reader::take` returns `IoError::Eof { offset, needed }` rather than panicking. That
matters: while reverse-engineering, "EOF at 2755 when 18 bytes were requested" is the
diagnostic that tells you which field you got wrong.

---

## 4. The parser: one long function, and why

`crates/terra-core/src/plr.rs`, `PlayerFile::parse`

The format is a straight-line sequence of fields — there is no tree, no random access. So
the parser is a straight-line function:

```rust
let v = r.i32()?;                       // format version
p.magic_a = r.u32()?;                   // "relo"
p.magic_b = r.u32()?;                   // "gic" + file type 3
```

Two ideas make it survivable across game updates:

**(a) Version gates.** Every field added in some patch sits behind `if v >= N`:

```rust
if v >= 82 { p.hair_dye = r.u8()?; }
if v >= 315 { p.team = r.u8()?; }
```

The numbers come from real files and from the game's own build: 1.4.4.0 writes 269,
1.4.4.9 writes 279, 1.4.5.8 writes 326. Fields are appended as the number grows, so a gate
is usually "does this field exist yet".

**(b) Trailing bytes.** After the last field we understand, whatever is left is kept:

```rust
p.trailing = r.rest().to_vec();
```

and written back on save. So an unknown future field survives the round trip even though we
cannot edit it. That is the single most important safety net in the project.

### The slot encoding, and the bug that proved the model

An item slot is not the same everywhere. `SlotKind` encodes the difference:

```rust
struct SlotKind { multi: bool, fav_min: i32 }
```

* `multi` = the slot stores an i32 stack count.
* `fav_min` = the version from which a favourite byte follows.

Equipment slots (`multi: false`) store neither a stack nor — before version 325 — a
favourite flag. Bank slots store a stack but no favourite byte.

Getting this wrong shifts *everything downstream* by a whole number of bytes. During
development the parse ended exactly 10 bytes late on every file, which turned out to be one
extra slot's worth of data: the **active** loadout does not store its 10 hide-visual bytes
(those live in the player-level `hide_visual` u16); only the three stored loadouts do.

**How that was found**, and the technique worth stealing:

1. Decrypt a real file and walk the layout, printing the byte offset after each section.
2. Compare against the payload length.
3. Sections are mostly zero bytes, so a wrong boundary is invisible… until the **server
   list terminator** (`i32 -1`) lands at the wrong offset. That sentinel is the anchor that
   makes misalignment obvious.

If you ever extend this parser, keep that tracing habit: `/tmp` scripts aside, the fastest
debug is "print the offset and the next four bytes after each block".

---

## 5. Proving correctness, not hoping for it

`crates/terra-core/src/file.rs`

`save_with_backup` is deliberately paranoid:

```rust
let plain = player.serialize();
let encrypted = crypto::encrypt(&plain)?;   // 1. build what we intend to write
fs::write(&bak, &existing)?;                // 2. copy the old file to .bak
fs::write(&tmp, &encrypted)?;               // 3. write somewhere else
let check = fs::read(&tmp)?;                // 4. read it back
if crypto::decrypt(&check)? != plain {      // 5. prove it round-trips
    let _ = fs::remove_file(&tmp);
    return Err(FileError::RoundTripMismatch(0));  // 6. refuse
}
fs::rename(&tmp, path)?;                    // 7. only now replace the original
```

Step 5 is cheap and catches an entire class of bugs (bad padding, off-by-one in a gate,
wrong slot width). The cost is one extra decrypt per save — microseconds.

The CLI exposes this to you:

```sh
tforge verify   <file.plr>   # decrypt → parse → serialise → encrypt == original bytes
tforge selftest <file.plr>   # edit, save, reload, assert every edit stuck
```

`verify` is the regression test you should run after touching `plr.rs`. `selftest` is the
one that proves editing works, not just round-tripping.

---

## 6. Where the item data comes from

`crates/terra-assets`, generated by `tools/gen_items.py`

Two sources, deliberately separate:

1. **From the installed game** (`tools/extract_from_install.py`): the `ItemID` constants are
   `const` fields in the .NET metadata, and the display names sit in an embedded resource
   `Terraria.Localization.Content.en-US.Items.json`. Reading those means the id↔name mapping
   always matches the version the player actually runs.
2. **From a stats snapshot** (`tools/snapshot_1.4.4.9.json`): max stack, rarity, tags,
   research goals, damage, defence. These live inside `Item.SetDefaults` in compiled IL and
   exist in no data file anywhere, so they cannot be read out.

Items newer than the snapshot get a real name and `estimated = true`, which the browser shows
as a note. That is an honest degradation, not a silent lie.

The DB is a flat JSON array, parsed once into a `OnceLock<ItemDb>`:

```
[id, pid, name, maxStack, rarity, tagsBitmask, researchGoal, damage, defense, estimated]
```

Compact arrays instead of objects keep the embedded file at ~400 KB and parse in ~10 ms.

---

## 7. The GUI: immediate mode, and the two traps

`crates/terra-gui/src/lib.rs`

egui has no retained widget tree. `App::ui()` runs top to bottom every frame; the only state
is in `App`. Two traps that cost real time here:

**Panel order.** Panels must be added before the central panel or they get no space:

```rust
self.top_bar(ui);
self.status_bar(ui);   // bottom panel: must come before the centre
self.side_left(ui);
self.side_right(ui);
self.central(ui);      // fills whatever is left
```

**Transient state must be stored.** A drag in progress is not remembered by egui between
frames, so `App::drag: Option<Drag>` holds it.

**Order of input handling matters.** Clearing a drag when the pointer is released *at the top
of the frame* looks harmless and silently breaks every drop: the release is consumed before
the slots are drawn, so no slot ever sees a drag on its release frame. The cancel-on-release
check therefore runs at the *end* of `ui()`, after the slots had their chance. Escape and
right-click cancels run at the top, because those are unambiguous.

### Drag and drop, as a state machine

```
drag_started()  → App::drag = Some(Drag { side, from: Some(slot), item })
pointer released over slot X
                → operations::drop_item / transfer_item
                → App::drag = None
pointer released over nothing
                → App::drag = None   (cancel)
```

`Drag::from` is `None` when the item came from the browser, which turns a drop into a copy
instead of a swap. Painting follows the pointer through a tooltip-layer painter
(`App::drag_ghost`), which is how the game does it too.

### One model, two characters

Stash mode is the same drag machine with one more dimension. A `SlotRef` only says
*container + index*, so `Side::{Primary, Stash}` is carried alongside it — in `Drag` and in
`App::selected_side`. `App::player_of(side)` / `player_mut(side)` are the only places that
decide which `PlayerFile` a reference means; every drawing and editing routine takes a
`Side` instead of reading `self.player` directly.

Cross-character moves go through `operations::transfer_item(src, dst, ...)`, which takes two
players because Rust will not let you borrow one `PlayerFile` mutably twice. Same-character
moves keep using `drop_item`. Both implement the same swap-or-copy rule, and both are unit
tested, so the "drop onto the stash" path is not special-cased UI code.

### Why the edit operations are free functions

`crates/terra-gui/src/operations.rs` takes `&mut PlayerFile` and returns nothing. No `App`,
no egui, no context — which is exactly why it can have unit tests:

```rust
#[test]
fn move_between_inventory_slots_swaps_contents() { ... }
```

One of those tests (`dropping_an_empty_item_is_a_no_op`) caught a real bug: dropping an
"empty" drag used to erase the destination slot. That class of bug is invisible in manual
testing and trivial to catch with a test.

### The catalogue layer

`crates/terra-gui/src/catalog.rs` turns 6,196 items into a list of rows:

```rust
enum Row { Header(&'static str), Item(i32) }
```

Browsing → grouped by tag (Weapons / Armour / Accessories / …), each group sorted by rarity
then name, with "first matching group wins" so nothing appears twice. Searching → the
fuzzy ranking from `terra-assets`, no headers. The UI then virtualises the flat row list
with `show_rows`, so only visible rows cost anything.

---

## 8. Item sprites: what an XNB is

`crates/terra-assets/src/sprites.rs`

Terraria stores each item's artwork as `Content/Images/Item_<id>.xnb`, an XNA content file:

```
'X' 'N' 'B' 'w'  version(u8)  flags(u8)  fileSize(u32)
compressed?  decompressedSize(u32) then payload
```

`flags & 0x80` means LZX-compressed, and the payload has a framing that is not part of the
LZX spec: every 32 KiB chunk is preceded by a big-endian length, and chunks whose first byte
is `0xFF` also carry their uncompressed length. After decompression you get the ordinary XNB
object graph — a type-reader table, then a `Texture2D` with surface format, width, height,
mip count and pixel data. Terraria always writes surface format 0 (straight RGBA8, one mip),
which is why the buffer can go straight to the GPU (`ColorImage::from_rgba_unmultiplied`).

Two decisions in the GUI are worth understanding:

* **Decode on demand, not up front.** All 6,134 vanilla sprites decode in ~0.3 s total, about
  0.05 ms each, so a lazy per-slot decode beats any import step. `SpriteCache` in
  `crates/terra-gui/src/lib.rs` keeps the textures actually on screen and evicts the rest;
  misses are cached too, so a missing file is never re-read per frame. Eviction is true LRU —
  a cache hit is *promoted* to the back of the queue — because a plain insertion-ordered
  queue turns scrolling the 6,196-item catalogue into an eviction machine that throws away
  the sprites of the equipped gear on screen.
* **Never upscale, boost only integers.** Drawing 1:1 is what the game does and it keeps
  pixel art crisp; but a 12 px coin would vanish in a 48 px slot, so sprites smaller than
  half the slot get an integer 2×. That rule is why coins and dirt blocks stay readable
  without swords looking blurry.
* **One frame, not the whole sheet.** Animated items are vertical strips: a soul's texture is
  22×88, four frames. `Sprite::frames()` recognises a strip geometrically (height an exact
  multiple of width) and the cache stores a cropped UV rect for the first frame. Drawing the
  full strip would silently render every animated item at 1/frames size — a bug visible only
  if you happen to look at the right item.

## 9. Exercises, if you want to change something

Each of these is a real, contained task:

1. **Add a read-only field to the Header tab.** Find the field in `plr.rs`, add it to the
   struct, parse and serialise it, then show it in `tab_raw`. Run `tforge verify` on all
   four sample players — if the gate or the width is wrong, it fails immediately.
2. **Add a new container.** Add a variant to `Bag`, wire `container`/`container_mut`, add a
   `section()` call. Run `cargo test -p terra-gui` — `containers::tests` will tell you if the
   multi/favourite rules disagree with the parser.
3. **Add an item category.** Add a `mask_` function in `catalog.rs` and a pill in
   `side_right`. The tests assert that every item lands in exactly one group.
4. **Animate the sprite frames.** `Sprite::frame_height()` already finds the frame boundary
   and the cache stores the top frame's UV rect; cycling through frames on hover (advance the
   UV rect's `min.y`/`max.y`) is a contained extension, and it makes the animated items look
   alive instead of frozen on their first frame.

---

## 10. Debugging recipes

* **"string length 18446744073709551615"** — you read a 7-bit length where there was none;
  your cursor is misaligned. Print the offset.
* **Parse succeeds but a field looks wrong** — check the version gate upstream of it; one
  missing byte shifts the rest.
* **Save loads in the editor but not in Terraria** — run `tforge verify` on the *output*.
  If that passes, the payload is self-consistent, so you are probably writing a semantically
  invalid value (e.g. a stack larger than the item's max, a prefix on an item that has none).
  The game clamps those, so the usual symptom is a changed value rather than a broken file.
* **UI state confusion** — remember there is no widget tree; every value you see came from
  `App`'s fields this frame.

#!/usr/bin/env python3
"""Extract item/buff/prefix IDs and display names from an installed Terraria or tModLoader assembly.

This is the "no new build needed" half of the item database: everything here is read out
of the game the user actually has installed, so a game update only requires re-running it.

    python3 tools/extract_from_install.py ~/.local/share/Steam/steamapps/common/Terraria/Terraria.exe out.json

What it reads:
  * CLR metadata `Constant` table -> `Terraria.ID.ItemID` / `BuffID` / `PrefixID` constants
    (persistent name -> numeric id). Field ownership comes from each TypeDef's FieldList.
  * Embedded manifest resource `Terraria.Localization.Content.en-US.Items.json`
    (or `en_US` in tModLoader) -> display names keyed by persistent id.
    The JSON is stored uncompressed but with trailing commas, so it needs a tolerant parse.

Requires: pip install dnfile
"""
from __future__ import annotations

import json
import re
import struct
import sys

import dnfile


def load_assembly(path: str):
    pe = dnfile.dnPE(path)
    if pe.net is None or pe.net.mdtables is None:
        raise SystemExit(f"{path} is not a .NET assembly")
    return pe


def constants_for(pe, type_name: str) -> dict[str, int]:
    """Return {field name: constant} for a static class such as Terraria.ID.ItemID."""
    mdt = pe.net.mdtables
    typedefs = mdt.TypeDef.rows
    fields = mdt.Field.rows

    val_by_field: dict[int, int] = {}
    for c in mdt.Constant.rows:
        try:
            rid = c.Parent.row_index
            v = c.Value.value if hasattr(c.Value, "value") else c.Value
        except Exception:
            continue
        if isinstance(v, (bytes, bytearray)):
            v = int.from_bytes(v, "little", signed=True)
        if rid and isinstance(v, int):
            val_by_field[rid] = v

    def name_of(x):
        return x.value if hasattr(x, "value") else str(x)

    out: dict[str, int] = {}
    for i, t in enumerate(typedefs):
        if name_of(t.TypeName) != type_name:
            continue
        start = t.FieldList[0].row_index
        end = typedefs[i + 1].FieldList[0].row_index if i + 1 < len(typedefs) else len(fields) + 1
        for rid in range(start, min(end, len(fields) + 1)):
            if rid in val_by_field:
                out[name_of(fields[rid - 1].Name)] = val_by_field[rid]
        break
    return out


def item_names(pe) -> dict[str, str]:
    """Display names from the embedded localization resource, keyed by persistent id."""
    base = pe.get_offset_from_rva(pe.net.struct.ResourcesRva)
    data = pe.__data__
    for r in pe.net.mdtables.ManifestResource.rows:
        if not r.Offset:
            continue
        name = r.Name.value if hasattr(r.Name, "value") else str(r.Name)
        if "Items.json" not in name or "en-US" not in name and "en_US" not in name:
            continue
        off = base + (r.Offset & 0x7FFFFFFF)
        length = struct.unpack("<I", data[off:off + 4])[0]
        raw = data[off + 4:off + 4 + length]
        if raw[:2] == b"\x1f\x8b":
            import gzip
            raw = gzip.decompress(raw)
        text = raw.decode("utf-8-sig")
        # Terraria's own JSON parser tolerates trailing commas; json.loads does not.
        obj = json.loads(re.sub(r",(\s*[}\]])", r"\1", text))
        names: dict[str, str] = {}
        for pid, entry in obj.get("ItemName", {}).items():
            if isinstance(entry, str):
                names[pid] = entry
            elif isinstance(entry, dict):
                names[pid] = entry.get("Name", "")
        return names
    raise SystemExit("no en-US Items.json resource found in this assembly")


def game_version(assembly_path: str) -> str:
    """Best-effort: read the sibling changelog.txt the Steam build ships."""
    import os
    d = os.path.dirname(os.path.abspath(assembly_path))
    for candidate in (os.path.join(d, "changelog.txt"),):
        if os.path.exists(candidate):
            m = re.search(r"Version (\d+(?:\.\d+)+)", open(candidate, encoding="utf-8", errors="replace").read(4000))
            if m:
                return m.group(1)
    return "unknown"


def main() -> None:
    if len(sys.argv) < 2:
        print(__doc__)
        raise SystemExit(2)
    src = sys.argv[1]
    dst = sys.argv[2] if len(sys.argv) > 2 else "itemids.json"

    pe = load_assembly(src)
    items = {k: v for k, v in constants_for(pe, "ItemID").items() if 0 <= v <= 100_000}
    buffs = {k: v for k, v in constants_for(pe, "BuffID").items() if 0 <= v <= 1_000}
    prefixes = {k: v for k, v in constants_for(pe, "PrefixID").items() if 0 <= v <= 1_000}
    names = item_names(pe)

    doc = {
        "source": src,
        "game_version": game_version(src),
        "items": items,
        "buffs": buffs,
        "prefixes": prefixes,
        "names": names,
    }
    with open(dst, "w") as f:
        json.dump(doc, f, indent=0)
    print(f"{src}")
    print(f"  items {len(items)} (max id {max(items.values())}), buffs {len(buffs)}, prefixes {len(prefixes)}")
    print(f"  names {len(names)}")
    print(f"  wrote {dst}")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Build the embedded item database for terra-assets.

Two inputs:
  1. An extraction from the installed game (tools/extract_from_install.py). Always required:
     it supplies the authoritative id <-> persistent-id mapping and display names for the
     exact game version the player runs.
  2. Optionally a metadata snapshot (max stack, rarity, tags, research goal, damage,
     defense) keyed by numeric id. The snapshot used here came from a 1.4.4.9 dataset;
     items newer than it get estimated stats and keep their real names.

    python3 tools/gen_items.py /tmp/ex1458.json [snapshot.json]

Writes crates/terra-assets/data/items.json.
"""
from __future__ import annotations

import json
import pathlib
import sys

TAGS = [
    "Melee", "Ranged", "Magic", "Sentry", "Summon", "HeadSlot", "BodySlot",
    "LegsSlot", "Accessory", "Vanity", "Hook", "Mount", "Minecart", "LightPet",
    "VanityPet", "Kite", "Drill", "Fish", "FishingCrate", "Ammo", "Tile", "Wall",
    "Painting", "Consumable", "Material",
]
TAG_BIT = {t: 1 << i for i, t in enumerate(TAGS)}
MAX_ID = 6200  # ignore sentinel constants above the real item range

PREFIX_NAMES = {

    24: "Awkward", 25: "Powerful", 26: "Mystic", 27: "Adept", 28: "Masterful",
    29: "Inept", 30: "Ignorant", 31: "Deranged", 32: "Intense", 33: "Taboo",
    34: "Celestial", 35: "Furious", 36: "Keen", 37: "Superior", 38: "Forceful",

    44: "Agile", 45: "Nimble", 46: "Murderous", 47: "Slow", 48: "Sluggish",
    49: "Lazy", 50: "Annoying", 51: "Nasty", 52: "Manic", 53: "Hurtful",
    54: "Strong", 55: "Unpleasant", 56: "Weak", 57: "Ruthless", 58: "Frenzying",
    59: "Godly", 60: "Demonic", 61: "Zealous", 62: "Hard", 63: "Guardian",
    64: "Armored", 65: "Warding", 66: "Arcane", 67: "Precise", 68: "Lucky",
    69: "Jagged", 70: "Spiked", 71: "Angry", 72: "Menacing", 73: "Brisk",
    74: "Fleeting", 75: "Hasty", 76: "Quick", 77: "Wild", 78: "Rash",
    79: "Intrepid", 80: "Violent", 81: "Legendary", 82: "Unreal", 83: "Mythical",
    84: "Legendary",
}


def split_pid(pid: str) -> str:
    """`FirstFractal` -> `First Fractal`; leaves all-lowercase ids alone."""
    import re
    words = re.sub(r"(?<=[a-z])(?=[A-Z])|(?<=[A-Z])(?=[A-Z][a-z])", " ", pid)
    return words.replace("_", " ").strip()


def main() -> None:
    if len(sys.argv) < 2:
        print(__doc__)
        raise SystemExit(2)
    extract = json.load(open(sys.argv[1]))
    snapshot = json.load(open(sys.argv[2])) if len(sys.argv) > 2 else None

    items_by_id: dict[int, dict] = {}
    for pid, iid in extract["items"].items():
        if pid == "None" or not (0 <= iid <= MAX_ID):
            continue
        items_by_id.setdefault(iid, pid)
    names = extract.get("names", {})

    snap_items = snapshot["items"] if snapshot else []
    max_id = max(max(items_by_id), len(snap_items) - 1, 0)

    rows = []
    estimated = 0
    unnamed = 0
    for iid in range(max_id + 1):
        src = snap_items[iid] if iid < len(snap_items) else {}
        pid = items_by_id.get(iid) or src.get("pid") or ""
        name = names.get(pid) or src.get("name") or ""
        if not name:
            # A few ids have no entry in the game's own Items.json (unused or
            # debug items). Fall back to the persistent id read as words:
            # "FirstFractal" -> "First Fractal", which is usually the real name.
            unnamed += 1
            name = split_pid(pid) if pid else f"Item #{iid}"
        est = iid >= len(snap_items)
        if est:
            estimated += 1
        tags = 0
        for t in src.get("tags", []):
            tags |= TAG_BIT.get(t, 0)
        rows.append([
            iid,
            pid,
            name,
            int(src.get("maxStack", 1)) if not est else 9999,
            int(src.get("rarity", 0)),
            tags,
            int(src.get("researchGoal", 0)),
            int(src.get("damage", -1)),
            int(src.get("defense", 0)),
            1 if est else 0,
        ])

    buffs = []
    if snapshot:
        for i, b in enumerate(snapshot.get("buffs", [])):
            if i == 0:
                continue
            buffs.append([i, b.get("name", "") or f"Buff #{i}", b.get("desc", ""), bool(b.get("debuff", False))])

    doc = {
        "dataset": "terra-forge item db",
        "game_version": extract.get("game_version", "installed"),
        "baseline_version": snapshot.get("version") if snapshot else None,
        "tags": TAGS,
        "items": rows,
        "prefixes": [[k, v] for k, v in sorted(PREFIX_NAMES.items())],
        "buffs": buffs,
    }

    dst = pathlib.Path(__file__).resolve().parent.parent / "crates/terra-assets/data/items.json"
    dst.parent.mkdir(parents=True, exist_ok=True)
    dst.write_text(json.dumps(doc, separators=(",", ":")))
    print(f"items {len(rows)} (estimated stats {estimated}, unnamed {unnamed}), buffs {len(buffs)}")
    print(f"max id {max_id}, wrote {dst} ({dst.stat().st_size} bytes)")


if __name__ == "__main__":
    main()
